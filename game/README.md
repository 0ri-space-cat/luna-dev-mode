# Игровые системы LUNA

Откройте `project.godot` в Godot 4 и запустите 2D-стенд. Исходник перенесён из последней отдельной 2D-ветки, ревизия `e52d05b`. Стенд содержит две технические комнаты, без утверждённых игровых локаций. Системы дверей, сохранений, физики предметов, взгляда Луны, камеры и защищённых команд палочки покрыты автоматическими проверками.

Стартовый остров, луга и другие игровые регионы проектируются в [дизайне мира](../docs/drafts/ETERNIA_WORLD_DESIGN.md). Подключение пиксельного HUD, героев, полноценного управления с геймпада и финального меню предстоит.
