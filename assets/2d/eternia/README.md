# Этерния 2D — приёмка первого арт-пакета

В первом ZIP: berry_tree, flower_bush, pink_crystals, moss_arch, oracle_pedestal, walking_fridge — шесть независимых RGBA-мастеров 512×512, плюс три бесшовных травяных тайла 64×64. Артефакты генерации требуют визуальной проверки на реальном уровне. oracle_pedestal — крупный предмет окружения, а не носимый Глаз Оракула.

Установка ZIP в корень клона репозитория:

    python3 tools/install_asset_pack.py /path/to/LUNA_Eternia_Asset_Pack_01.zip

Без --force существующие файлы не перезаписываются. Для декоративных объектов предусмотрен optional loader в meadow_decor_2d.gd; без файлов остаются процедурные заглушки. Спрайты walking_fridge и berry_tree пока не подключены как анимированные Entity — их конечности нужно разделить на слои и проверить.

Трава без чёрных контуров по краям тайлов. Сначала сравнить скрин повторения 10×10 с двумя построенными полянами. Не запекать цветы и кристаллы в травяную основу.
