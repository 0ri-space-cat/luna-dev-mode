# Этерния 2D — первая установленная арт-партия

**Состояние в `feat/2d-runtime-foundation`, 08.11.2026:** файлы уже закоммичены. Отдельный ZIP для запуска поляны больше не требуется.

- `terrain/grass_1.png` … `grass_12.png`: двенадцать PNG-тайлов 64×64. Используются непосредственно `scripts/2d/terrain_2d.gd`; процедурный тайл — резерв на случай отсутствующего файла.
- `props/flower_bush.webp`, `pink_crystals.webp`, `moss_arch.webp`, `oracle_pedestal.webp`, `walking_fridge.webp`, `berry_tree.webp`: шесть отдельных прозрачных WebP 256×256.
- Текущие травяные тайлы и пропсы перечислены в [`manifest.json`](manifest.json). Проверка размеров/альфы и стыков — `python3 ci/check_terrain_seams.py`.

**Статус подключения:** кусты, кристаллы, арка и постамент Оракула размещены в 2D-поляне. Иллюстрации `walking_fridge` и `berry_tree` не подменяют игровых существ: у них ещё нет согласованных ракурсов, раздельных конечностей и проверенных циклов. Кодовые скалы и вода всё ещё требуют художественной замены.

Исходный пакет мог содержать более крупные мастер-изображения, но **актуальные файлы в этой папке — 256×256 WebP**. Не путать иллюстрации с готовыми игровыми анимациями.

Новые ассеты добавлять небольшими партиями, сохранять исходник, критерии приёмки и QA. Следующая партия: [рельеф и стыковки](../../../docs/art/NEXT_ETERNIA_ASSET_BATCH.md); следить за [визуальным аудитом](../../../docs/VISUAL_ART_AUDIT.md). Старые команды установки ZIP в `tools/install_asset_pack.py` оставлены для воспроизводимого импорта внешних пакетов.
