# LUNA · комплект интерфейса для Godot 4

Откройте `project.godot` и запустите проект. В демо можно переключить семь тем, посмотреть окно на примере клёна, открыть консоль Юки и вызвать плашку. `preview.tscn` содержит демонстрационные данные.

В `assets/ui/pixel-v1` лежат прозрачные PNG рамок, кнопок, вкладок, полей, слотов, полос ресурсов, курсоров, значков способностей, портретов и рюкзаков. Размеры и отступы для растяжения рамок перечислены в `manifest.json`. Текст и числа выводятся отдельно. Шрифт Press Start 2P включает кириллицу, лицензия лежит рядом. Иконка клёна сделана для примера. Портрет объекта передаётся как Texture2D.

## Подключение окна

Перенесите `hack_window.tscn`, `hack_window.gd`, `retro_ui_2d.gd` и `assets/ui/pixel-v1`, сохранив относительные пути от корня проекта. Добавьте экземпляр сцены в слой интерфейса. Для текстур включите Nearest.

- `set_character_theme(id)` переключает тему отдельно от игрового персонажа.
- `show_object(identity, specs)` принимает имя (`name`), идентификатор (`id`), миниатюру (`portrait`), состояния `active` и `alive` и, при необходимости, силу сигнала `signal_strength` от 0 до 4. Дальность и шкалу рассчитывает игра.
- У строки задаются `key`, `label`, `tab`, `kind`, `value`. Числу можно дать `min`, `max` и `step`, списку — `options`. Категории совпадают с идентификаторами семи вкладок.
- Подключите `parameter_requested`, `save_requested`, `copy_requested`, `delete_requested` и `close_requested` к игровой логике. После принятого изменения передавайте обновлённые данные. После успешной записи вызывайте `show_saved()`: подтверждение видно одну секунду. Решение о доступе, подтверждение удаления и запись остаются у игры.

## HUD, консоль и уведомления

- `hud.tscn` принимает тему через `set_character_theme(id)`, а значения ресурсов, карту, метки, предметы и задания через `set_state(state)`. Поля примера собраны в `preview.gd`. `slot_requested`, `shortcut_requested` и `tool_cycle_requested` передают выбор игровой сцене. При смене инструмента его название на короткое время появляется над слотом.
- `yuki_console.tscn` принимает демонстрационные данные карточек, цели и кода через `set_program(program)`. Игровые команды подключаются к сигналам `card_requested`, `world_requested` и `run_requested`.
- `message_panel.tscn` оформляет обычную плашку и подтверждение, а список заданий входит в HUD.

## Артефакты

В `assets/ui/pixel-v1/items/` лежат 17 иконок из актуального авторского списка и отдельная палочка Луны. Имена в `manifest.json` — ключи иллюстраций. Игровые идентификаторы и поведение назначаются при интеграции. [Лист для просмотра](../../previews/ui-artifacts-pixel.png) · [Авторский перечень](https://github.com/0ri-space-cat/luna-dev-mode/blob/main/docs/canon/25_V6_FINAL_AUTHOR_ARTIFACT_ROSTER.md).

Портреты, рюкзаки и новая партия иконок выполнены в ImageGen. Их исходники находятся в `../../assets/ui-pixel-v1/regen-retro/`, задания для иконок — в [PROMPTS.md](../../source/ui-pixel-v1/PROMPTS.md#d-палочка-и-17-артефактов). Пересборка PNG из локальных исходников запускается командой `node tools/export_retro_ui.mjs` с установленным ImageMagick. Игровая интеграция остаётся отдельным шагом.

Старые 2D-поляна и 3D-сцена выведены из работы. Не использовать их для интеграции этого комплекта.
