# Передача арт-партии

**Приоритет 27.11:** [арт-мануал и готовые промпты](../../docs/art/VISUAL_PRODUCTION_PLAYBOOK.md). Начать с фактической инвентаризации и P0-калибровки; продолжать недостающие спрайты, UI обсуждать с автором, модульный мир после контрольной партии. Не переделывать одобренное.

1. Начать с [реестра ассетов](ART_ASSET_REGISTER.md). Самые свежие прямые правки автора отражены в карточках героев. Выбранный исходник Тоффи лежит отдельно и служит эталоном для поворотов.
2. Для нового окна использовать подготовленные состояния кнопок и рамок в семи темах. Проверить их в актуальном нижнем правом блоке HUD с данными выбранной цели, в узком окне, при длинных параметрах, при фокусе с клавиатуры и геймпада. Стенд показывает цвет и размеры; игровой ввод, действия и доступы относятся к интеграции.
3. Сверить [пять ракурсов](characters/previews/classic-five-views.png) и переходы деталей между ними. У Они по последней правке автора колени без швов во всех позах. Стойки Они сверены. Ходьба и бег ожидают новых кадров от этой базы. Для остальных друзей продолжить ходьбу, бег, прыжки и действия с предметами. Для Луны опираться на существующий банк взмахов, отдельный слой использовать для подставляемых предметов. Для клонов использовать существующую Chibi.
4. Для слаймов проверить точки опоры и читаемость обеих форм на лугах, затем собрать общий цикл прыжка. Следующую фауну брать из действующего мануала §04 и региональных глав. Палитра конкретного появления пока рабочая.
