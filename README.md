**Следующий пакет:** разобраться с исходными регрессиями восстановления; продолжить обычные встречи без зависимости от даров, перенос Тоффи с сохранением ID, затем расширить реальные непрерывные пространства по региональным главам. Тихие зоны — полноценная часть географии: свободный обход, обычная фауна с индивидуальными параметрами, созерцание и экспериментирование без обязательного пазла, награды или тайника. Не назначать окончательные координаты без карты/P0. Точный прогресс: [handoff](docs/SKELETON_BUILD_HANDOFF.md), [CI](https://github.com/0ri-space-cat/luna-dev-mode/actions).
