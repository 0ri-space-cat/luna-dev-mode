# LUNA: Dev Mode 🌙

**Единая актуальная точка входа:** [Производственный мануал LUNA](docs/manual/00_LUNA_PRODUCTION_MANUAL.md) (23.11.2026, M0.2). В нём текущие правила проекта, шесть смысловых слоёв игры, девять этапов переработки, статусы решений, известные противоречия и точная инструкция следующему чату.

LUNA: Dev Mode — тёплая пиксельная 2D-игра в 3/4 про Луну, живую Этернию, настоящие редактируемые параметры, исследования в духе метроидвании и глубокие необязательные метатайны. Обычный финал доступен без скрытого слоя. Точные решения уточняются в мануале.
