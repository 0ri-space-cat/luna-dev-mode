# LUNA: Dev Mode 🌙

Уютное пиксельное приключение-песочница о Луне и Этернии, настоящей магии, друзьях и скрытых системных законах.

**Основная ветка main. Единственный основной игровой запуск Adventure.** Godot 4.3, открыть game/project.godot, F5. Скелет 2D+Z, не финальная графика.

- [Основной сценарий I–IX](docs/scenario/README.md) — одна региональная редакция и дополнительные банки.
- [Арт-производство](docs/art/ASSET_INDEX.md) · [ассеты](assets/approved/README.md) · [референсы](references/README.md).

- [Архив](DEVELOPMENT%20HISTORY/README.md) — предыдущие варианты, старый обзор и устаревшие инструкции.
