Этерния — тёплое пиксельное приключение-песочница, настоящая магия и параметры мира, метроидвания, друзья, знание и необязательные глубокие секреты. В обычном финале прото-Луна просит о помощи, её голос исчезает. Не создавать второй канон и не восстанавливать отвергнутое. Этапы: сценарий → сквозной аудит → скелет → наполнение, ассеты, интеграция и проверка.
