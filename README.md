# LUNA: Dev Mode 🌙

**Единый актуальный источник проекта:** [авторская библия V6](docs/canon/20_V6_AUTHOR_ONLY_BIBLE.md) + [последние решения автора](docs/canon/30_V6_FINAL_AUTHOR_CHOICES_AND_IMPLEMENTATION_RULES.md). [Итоговый дизайн-handoff](docs/drafts/LUNA_MASTER_CONCEPT_AND_SKELETON_HANDOFF_2026-11-20.md).

## Код: старые прототипы отвергнуты

**Решение автора 20.11.2026:** две прежние реализации не входят в новую LUNA:

- **Первый 3D-graybox на `Node3D / CharacterBody3D`**: устаревший неудачный прототип, **удалён из активной ветки `main`**. Не использовать его сцену, движок, архитектуру и UI как базу игры.
- **Старый 2D-прототип с кукольными руками/ногами** (`luna_puppet_2d.gd`, `universal_round_legs_2d.gd` и сопутствующие старые сцены): **отвергнут** и не должен возвращаться ни как визуальный эталон, ни как стартовая реализация.

Их исторические коммиты остаются доступными только в истории Git; это архив, не план миграции. **Нельзя предлагать ещё одну «миграцию 3D→2D» как начало создания LUNA.** Технические документы об этих прототипах относятся к истории.

## Где искать новое 2D-ядро

В репозитории есть отдельная рабочая ветка [`feat/2d-meta-runtime-scaffold-20261116`](https://github.com/0ri-space-cat/luna-dev-mode/tree/feat/2d-meta-runtime-scaffold-20261116), где реальная точка входа `res://scenes/runtime2d/sandbox.tscn`, а новая архитектура располагается в `scripts/runtime2d/`. Это **незавершённая изолированная техническая ветка**, не утверждённая автоматически как окончательный скелет всей игры. В ней могут сохраняться исторические 3D-файлы для прошлых тестов: **их нельзя считать частью будущей игры**. Перед следующим развитием нужно сравнить этот 2D-каркас с V6 и последними решениями автора. Новую игру вести в отдельной 2D-ветке, не в старых 3D/кукольных ветках.

Ветка `main` служит каноном, документацией и арт-источниками; после очистки здесь **нет запускаемого устаревшего прототипа Godot**. Для создания новой игры нужен отдельный Godot-проект в активной новой ветке с несколькими регионами и типами управления. Допускается точечное переиспользование **только независимо проверенного кода**, если он соответствует V6, без требования сохранять старый движок или старые сцены.

Важна утверждённая игра: связная 2D Этерния, системный взлом, метаоткрытия и настоящая архитектура с временными ассетами. Финальная графика будет сделана позже.
