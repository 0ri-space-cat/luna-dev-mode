# LUNA — UI kit v2

Первый набор для согласования и подключения в Godot 4.

- 2 иллюстрации PNG: портрет Луны, рюкзак с пустой передней областью. Созданы встроенным image_gen по авторским референсам.
- 24 SVG-значка, 5 панелей, 6 состояний/вариантов кнопок, 4 состояния ячеек, 4 текстуры шкал, 2 круглые рамки. SVG созданы как редактируемая геометрия.
- preview.html — автономная галерея, manifest.json — размеры и поля растяжения.

Текст, цифры, сетка предметов, индикаторы и интерактивные зоны накладываются движком. Рюкзак и круглые рамки масштабируются с сохранением пропорций; иллюстрацию рюкзака целиком нельзя растягивать через NinePatchRect. Панели, кнопки, слоты и шкалы имеют поля nine_patch в порядке left, top, right, bottom. Для иконок с прозрачностью задавать keep aspect. Внутренние области круглых рамок прозрачные; портрет или содержимое мини-карты надо маскировать отдельно.

Портрет — новый вариант по авторскому дизайну, а не утверждённый финальный образ. Рамки диалогов и шкалы не означают реализацию соответствующих игровых механик. Дефолтная кнопка disabled должна дополнительно получать disabled в Godot: текстура сама не блокирует нажатия. Состояния hover/pressed/selected задаёт движок. SVG поддерживаются Godot как импортируемые Texture2D.

В этом проходе графика подготовлена и скопирована в локальный проект assets/ui/v2. Существующие экраны пока не переоформлены этим набором. Нет загрузки в GitHub и перехода к 3D.

Изменения иконок описаны в CHANGES_V2.md. Сравнение: comparison.png; просмотр размеров: icons-review.png.
