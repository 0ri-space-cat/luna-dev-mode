# Approved Luna animation cels

Updated locally on 2026-11-10: 20 walk cels, 13 cast cels, 3 closed-eye cels and 5 hair-flutter cels. Five approved idle masters remain in explorer_v1. Five authored views cover eight gameplay directions by mirroring profile and diagonals.

Built-in ImageGen generated each cel separately. No program-drawn character parts, sprite-sheet extraction or source downsample was used. Rejected generations included a swapped wand hand, duplicated passing pose and a high-march knee; these were redrawn before registration.

These PNGs are raw archival sources and may contain low-alpha background noise. The only textures consumed by gameplay are the sanitized copies under assets/2d/characters/luna/explorer_animation/. Runtime alpha is binary, transparent RGB is zero, and visible character RGB matches the raw source. After the user's haze report, every candidate passed white/cyan QA and a real Godot render before registration. Raw generation previews are not used as final assets.

See docs/LUNA_ANIMATION_PREVIEW.md for controls, inventory, exact prompt specifications, checks, rendering evidence and remaining limitations. Manifest source/runtime hashes make the preparation reproducible.

The Nov 10 targeted hat and gaze-aligned cast revisions, preserved originals, three-cel anticipation timing and rear-diagonal registration offsets are documented in docs/LUNA_ANIMATION_PREVIEW.md. The close cast cels are retained as brief anticipation frames.
