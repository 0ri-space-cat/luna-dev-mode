## Как использовать после загрузки оригиналов

- **Актуальная игра полностью 2D.** Старое описание «стилизованное 3D как 2D» относится к предыдущей концепции. Turnaround сохраняет внешность героини, но новые спрайты, ракурсы и риг делаются в `Node2D`/`Skeleton2D`.
- Визуальный ориентир: рисованная выразительная анимация, тёмно-фиолетовый контур, зелёные поляны, сиреневые скалы, бирюзовая вода, неоновый HUD.
- **Актуальное прямое решение автора 08.11.2026:** окно взлома только **вертикальное** (высота заметно больше ширины, ориентир 390×610); широкие редакторы и дополнительные столбцы запрещены, даже если они встречаются на концептах. Копирование и удаление — иконками; «Сохранить» — с надписью. Текст UI — русский, технические ID — на английском по правилам Глаза Оракула.
- Дизайн-концепт нельзя выдавать за скриншот игры или подсовывать в сцену как единый JPG. Реальный мир собирается тайлами, пропсами и отдельными анимированными существами.
- Для новых ассетов следовать [2D-канону](../../../docs/canon/00_START_HERE.md), [техническому плану](../../../docs/canon/11_2D_IMPLEMENTATION_PLAN.md) и [ближайшему пакету](../../../docs/art/NEXT_ETERNIA_ASSET_BATCH.md).

После нахождения оригинального ZIP его четыре изображения нужно загрузить сюда без подмены; до этого текущая сцена и находящиеся в Git референсы являются доступным материалом для производства.
