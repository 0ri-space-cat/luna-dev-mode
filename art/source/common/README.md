# LUNA UI v3

Расширенный локальный набор UI-компонентов и состояний. Иконки v2, портрет и рюкзак сохранены. Новые компоненты: поля ввода, tabs, dropdown, switches, slider thumbs, scrollbars, панели, уведомления, badges, overlays и дополнительные значки категорий/действий. Все значения и подписи накладываются движком. Поля растяжения указаны в manifest.json. SCENARIOS.md описывает назначение компонентов.

Это подготовленные ассеты; существующая игра автоматически на v3 не переключается. Новые механики наличием графики не объявляются реализованными. Предыдущие версии сохранены.
