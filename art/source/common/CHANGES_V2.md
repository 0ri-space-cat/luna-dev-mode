# Иконки v2

Все 24 значка пересмотрены. У настроек новая симметричная шестерёнка с восьмью одинаковыми зубьями и концентрическим отверстием. Рюкзак получил клапан, карман и лунный знак; замок сохраняет отдельный силуэт. Журнал стал закрытым блокнотом с переплётом и закладкой, карта — складной картой с маршрутом. Магия — палочка с полумесяцем; неизвестный предмет — загадочный мешочек вместо ещё одного многогранника. Значки помощи, копирования, сохранения и диалога получили собственные детали и цветовые акценты.

Функциональные пары +/− и стрелки оставлены простыми для узнаваемости. Центровка и оптические поля приведены к общей сетке 64×64. Линейная толщина преимущественно 3.5 единицы, второстепенные линии 2.5–3. Цвет не должен быть единственным различием.

Исходный v1 сохранён. Это замена графики, игровые функции не менялись. PNG-иллюстрации и остальные компоненты перенесены из v1 без изменения.
