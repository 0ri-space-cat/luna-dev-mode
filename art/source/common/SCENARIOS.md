# UI v3 — покрытие сценариев

Графические компоненты для следующих состояний. Наличие ассета не означает наличия игровой механики. Кики, диалоги, ресурсы и ряд экранов пока требуют реализации.

## hack

- выбранный объект
- число: обычное / фокус / ошибка
- TRUE/FALSE
- enum раскрыт
- вкладка пустая
- параметр только для чтения
- длинное имя / много строк
- контекстная подсказка
- COPY / DELETE / DONE

## inventory

- пустой рюкзак
- занятая ячейка
- выбранный предмет
- заблокированная ячейка
- USE / DROP / TRANSFER
- переполнение / отказ
- нет доступной цели

## magic

- пустой сокет
- выбранный блок
- валидный рецепт
- ошибка рецепта
- описание блока
- недоступное действие

## dialogue

- говорящий и текст
- варианты ответа
- выбранный ответ
- продолжение
- портрет отсутствует

## journal

- нет записей
- новая запись
- категория выбрана
- длинная заметка

## map

- рамка миникарты
- маркер игрока
- неизвестная точка
- портал
- карта недоступна

## settings

- переключатель
- громкость
- выбор языка
- полный экран
- сброс настроек / подтверждение

## feedback

- сохранение
- успех
- ошибка сохранения
- предупреждение
- пауза
- подтверждение удаления

## onboarding

- подсказка параметра
- знак справки
- объяснение кнопки
- действие недоступно


Правила: текст и значения остаются в Godot; отдельная рамка растягивается по nine_patch, значки — с сохранением пропорций. Модальная подложка блокирует ввод только через отдельный Control, сама декоративная текстура этого не делает. Числовой ввод валидируется типом, диапазоном и шагом из реестра.
