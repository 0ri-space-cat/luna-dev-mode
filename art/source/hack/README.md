# Pixel Hack Inspector v2

66 prepared SVG components from the historically approved 6 November vertical editor, including frame/control variants, state textures, palette swatches, scroll pieces, feedback and 16 pixel glyphs. Use nearest filtering and the nine_patch metadata. Labels and values are rendered by the engine.

preview.html is the component gallery; STATE_COVERAGE.md describes the states and the limits of the presentation prototype. DIRECTION.md preserves the **retired vertical layout** for reference. The active wider 2D layout is specified in [docs/art/HACK_EDITOR_APPROVED_LAYOUT.md](../../../docs/art/HACK_EDITOR_APPROVED_LAYOUT.md). Validation: 66 imported textures, no errors, local Godot 4.7.2; selected interactions checked in browser. The game editor has not yet been restyled to consume this pack.
