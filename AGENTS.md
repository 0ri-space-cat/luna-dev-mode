# LUNA: Dev Mode — вход для агентов

Открой [единый производственный мануал](docs/manual/00_LUNA_PRODUCTION_MANUAL.md): §12 (текущий шаг), §00.4 (правила), §09.28 (план), §08.26–08.29 (приоритет автора). В новом чате изучить актуальный мануал, [девять глав](docs/scenario/README.md), нужные арт-источники, код и фактический CI. Работать по-русски. Единственная основная ветка main, единственная игра Adventure, F5 в Godot 4.3. Архив не активное задание. Не плодить промпты, handoff, GDD или ветки; обновлять §09/§11/§12 и связанные главы. Самостоятельно решать технические проблемы; канон меняет автор. Проверять HEAD, не форсировать и не перетирать чужую работу. Статусы и реальные тесты обязательны.
