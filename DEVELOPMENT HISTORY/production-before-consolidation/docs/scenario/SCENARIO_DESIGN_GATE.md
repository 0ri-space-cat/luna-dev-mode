# Обязательный редакционный барьер сценария LUNA
Источник законов — [§08.26–08.29 мануала](../manual/00_LUNA_PRODUCTION_MANUAL.md). Этот файл — инструкция агентам, не второй канон.
1. Сначала опиши назначение места, жителей, эстетику и чем интересно пространство без пазла. Затем выбирай естественные механики. Проверяй происхождение реквизита; техническая коллизия не обоснование лора. Запрещено возвращать отменённое под новым названием.
2. Не ставь головоломку на каждый экран. Оставляй несколько тихих зон без секретов в каждом биоме. Сравнивай способы раскрытия тайников между соседними главами; не повторяй «за спрайтом ниша с руной». Используй звук, экологию, время, композицию, Камеру, реальные свойства и изобретательность.
3. Для каждого секрета фиксируй: место и естественную причину, заметный намёк, требуемое знание/действие, реальный результат, альтернативы, безопасный выход, статус. Большие секреты — независимые зацепки без циклической зависимости; первое открытие Белой Пустоты только физическое, адрес до входа не раскрывать.
4. Обычная география и встречи всех шести друзей доступны без скрытых инструментов. Не делать подарки экзаменами, не превращать секреты в флаги. Значимые находки требуют наблюдения. Не вводить вид, артефакт, новый канон без автора.
5. Постоянная AM-экология, региональные дефекты Забытого края, повседневные встречи и случайные overload-аномалии раздельны. Последние невозможны до первого реального overload, крайне редки и ограничены местами. Не хоррор.
6. Перед коммитом сверить актуальный мануал, главы, арт и код; отметить [АВТОР]/[РАБОЧЕЕ]/[РЕАЛИЗОВАНО], расхождения, отменённые ID, карту, тесты и безопасную миграцию. Не считать успешный коммит реализацией. Не заказывать массовые ассеты до проверки масштаба и постановки.

7. Свобода рождается вокруг ограничений: общие/индивидуальные параметры, конечные модули, временные эффекты и реальная геометрия. Не подменять ограничения произвольным кодом и не запрещать законные комбинации по ID пазла. Призма проявляет шифр, не переводит. Перед реализацией открыть [кодовую передачу](../SKELETON_BUILD_HANDOFF.md).
