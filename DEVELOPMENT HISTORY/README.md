# DEVELOPMENT HISTORY

Исторические проектные материалы LUNA: Dev Mode. Перемещены 23.11.2026 по просьбе автора.

**Читать как референс прежних идей и происхождения решений. Не использовать как параллельную спецификацию.** Единственный актуальный мануал: [LUNA Production Manual](../docs/manual/00_LUNA_PRODUCTION_MANUAL.md).

- [docs/canon](docs/canon/) — прежние библии и авторские поправки; решения не аннулированы самим перемещением.
- [docs/scenario](docs/scenario/) — предыдущие сценарные версии.
- [docs/drafts](docs/drafts/) — ранние концепты, бестиарий, реестры.
- [docs/audits](docs/audits/) — прежние ревизии.
- [docs/engineering](docs/engineering/) — прежние инженерные контракты и дорожные карты; текущий код и тесты находятся в game/.
- [archive](archive/) — более ранний архив, сохранён целиком.
- [branch-recovery](branch-recovery/) — материалы из отдельных веток V6 со ссылками на исходные срезы.

Содержимое исторических деревьев не редактировалось. Их относительные ссылки, выходящие за архив, могут вести к прежним путям. Для оригинальной навигации откройте [снимок дерева до перемещения](https://github.com/0ri-space-cat/luna-dev-mode/tree/947cb6859c8715b31b3b785eafc3b09234757bdc). Актуальные ссылки из мануала ведут на перенесённые материалы или неизменённые рабочие файлы. Рабочие арт-гайды в docs/art, assets, references и game не архивированы.
