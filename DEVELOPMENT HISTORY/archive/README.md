# Архив LUNA

Материалы для справки. Внутри могут встречаться прежние карты, составы артефактов, интерфейсы, сценарии и правила, у которых на момент написания стоял статус «канон».

- [Исторические предложения](design/proposals/) — рабочие карты, ранние варианты маршрутов, сетки загадок и визуальные исследования.
- [Материалы из прежних веток](design/branch-proposals/) — география V3/V5, экология, маршруты приобретения артефактов, сценарии и подсказки. Сохранены как источники идей.
- [Прежние библии](design/previous-bibles/) · [ранние издания](design/earlier-editions/) · [старые описания систем](design/early-system-notes/).
- [Legacy-арт](legacy/) — прошлые интерфейсы, непиксельные изображения, исследовательские варианты и исходники для возможной пиксельной переработки.

Актуальные решения находятся в [V6](../docs/canon/00_START_HERE.md), активный комплект находится в [одобренных ассетах](../assets/approved/README.md).
