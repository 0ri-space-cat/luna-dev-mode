# LUNA 2D — атласный импортёр и проверка швов

\`python3 -m pip install Pillow\`

\`python3 tools/asset_importer.py path/to/sheet.json\`

Генератор рисует объекты **отдельно по фиксированным одинаковым ячейкам**. Нельзя полагаться на автоматическую нарезку по видимым контурам — руки, мелкие предметы и полупрозрачные эффекты легко ломают такую процедуру.

Пример \`sheet.json\`:
\`\`\`json
{
  "source": "sheet.png",
  "cell_size": [512, 512],
  "grid": [2, 3],
  "output": "export",
  "seam_tolerance": 10,
  "sprites": [
    {"name": "tree_round", "cell": [0, 0], "pivot": [0.5, 1.0]},
    {"name": "crystal_purple", "cell": [1, 0], "pivot": [0.5, 1.0]}
  ]
}
\`\`\`

Выход: отдельные RGBA PNG с исходным размером каждой ячейки и \`index.json\` (pivot, SHA-256). Импортёр проверяет размер атласа, дубликаты, пустые ячейки, выход за границы, безопасность имён. Если для записи \`"seamless_tile": true\`, он сравнивает противоположные границы и откажется экспортировать заметно разошедшийся тайл. Проверка швов **не заменяет** визуальный тест повторения 10×10 и стыковки соседних типов поверхности.

Пакет персонажа нужно разделять на отдельные листы: риг, эмоции, особые позы. Алгоритм не распознаёт ошибки анатомии автоматически: перед одобрением обязательно пересчитать конечности и проверить анимации в движении.
