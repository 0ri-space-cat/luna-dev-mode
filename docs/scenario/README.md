# Сценарий LUNA: Dev Mode

Экранная редакция этапа 8, возобновлённая автором в M3.63; детальная рабочая редакция I–II в M3.64 и III–IV в M3.65, V–VII в M3.66, VIII–IX в M3.67; исходная постановка M3.29 с авторской сквозной ревизией M3.36 (магия, рикошет, призрачные обходы и Консоль). Дополнительно M3.41: Администратор, карма, постоянный разлом и новая география P01/Чёрной Пустоты. Общие законы и статусы — [единый производственный мануал](../manual/00_LUNA_PRODUCTION_MANUAL.md). Архивы — история; новые постановки не равны реализованному коду.
