# Сценарий LUNA: Dev Mode

**[АВТОР 27.11, ПРИОРИТЕТ]** §08.26 и [редакционный барьер](SCENARIO_DESIGN_GATE.md). Все девять глав имеют авторские поправки. Перед интеграцией устранить оставшиеся противоречия прежних строк, проверить карты и тесты. Не считать текстовую ревизию готовым кодом.
