**Редакция 23.11.2026.** Дополнение к [сценарию 00](00_LUNA_V6_INTEGRATED_WORLD_SCENARIO_2026-11-22.md) и [новым авторским поправкам 10](10_V6_AUTHOR_REVISION_FAIRY_ECHO_YUKI_ORI_TOFFI_2026-11-23.md). [А] — прямое авторское правило/ядро; [Р] — предложенная конкретная постановка для плейтеста. Координаты, геометрия и создаваемые по сценарию предметы ещё **не реализованы**; не выдавать их за готовые уровни. Единый мир, без обязательного прохождения семи сюжетных кампаний.

## 0. Договор против повторов и «нейрослопных» микрозадач

- Каждый крупный открытый регион содержит **обычную жизнь**, **одну игру на физику/существа**, **один неожиданный побочный эксперимент с параметрами**, **одну пространственную догадку**, **хотя бы один необязательный секретный слой** и **реальную награду** за любопытство. Число ниже — рабочая сетка для проверки плотности, не квота добивания контента.
- Не больше одной близкой по устройству сцены «изменить агрессию врага» или «подвезти себя на ездовом звере» на коротком маршруте. В остальных случаях менять способ мыслить: причинные программы, зрение, время, голос/звук, размеры, эхо, адрес, природные физические потоки, фазы суток, отношения нескольких существ друг к другу.
- У каждого пазла должны существовать **наблюдаемая постановка**, **правило, которое можно проверить**, **физический результат**, **один вариант честного обхода** (если системные механики допускают) и **что остаётся после решения**. Записи в журнале не разгадывают за игрока.
- Награда класса `SHORTCUT` действительно оставляет повторно используемый выход. `SYSTEM_KNOWLEDGE` применимо ещё в нескольких местах. `WORLD_EVENT` меняет мир/население. `CHARACTER` — личная встреча, самостоятельная без сундука. `ARTIFACT` — только уже существующий оригинал из 16. `MUSIC` — действенная мелодия.
- **Нельзя** вешать «найди ягодку/листочек/поправь табличку/принеси колокольчик» на живую фауну ради видимости наполнения. Допускаются шутки и обыкновенный быт без специальных наград.

## 3. Пять изнаночных проходов и восемь специальных дверей

| Feature ID | Обычный вид → изменение закона → что внутри |
| --- | --- |
| `ET_CRYSTAL_UNDERSIDE_PASSAGE` | Глухая кристальная стена → голубой проход, мост A → `ET_UNDERSIDE_REFUGE_01` |
| `UNDERSIDE_MOUNTAIN_CLIFF_SEAM` | Сплошная горная скала → настоящая голубая арка → карман под горой, ветер и след о взгляде |
| `UNDERSIDE_LUMA_FOUNDATION` | Глухое основание виадука → технический нижний ход → сервисный путь и связь с обычной частью города |
| `UNDERSIDE_FOREST_BOULDER` | Совершенно обычный валун → скрытая голубая тропа → забытая поляна и местная необычная экология |
| `UNDERSIDE_COAST_CLIFF_SEAM` | Твёрдый береговой утёс → сухая скрытая ниша → наблюдаемая физика прилива, безопасный возврат |

**Двери, видимые только в изнанке (4):** `DOOR_UNDERSIDE_REFUGE` (кристальная пещера), `DOOR_UNDERSIDE_MOUNTAIN` (горная ремонтная камера), `DOOR_UNDERSIDE_LUMA` (городская техкомната), `DOOR_UNDERSIDE_COAST` (береговая сухая ниша). Они принадлежат единому resolver и не создают копий одних и тех же помещений.

**Двери с пропадающей коллизией при закрытых глазах (4):** `DOOR_EYES_CLOSED_CRYSTAL` (рядом с мостом II), `DOOR_EYES_CLOSED_FAIRY` (миниатюрный интерьер), `DOOR_EYES_CLOSED_LUMA` (городская кладовая), `DOOR_EYES_CLOSED_MOUNTAIN` (горная проходная плита). Можно использовать `CLOSED_EYES`-состояние героя и общий `COLLIDER_DISABLED_WHEN_ACTOR_EYES_CLOSED`; это **предлагаемые инженерные имена**, не автоматически утверждённая вкладка.

## 6. Три системы письменности и видимости

**[А] Слои разделены:**
1. **Древние текстовые руны** мира, содержат русскоязычный смысл, имена персонажей, короткие бытовые фразы и подсказки; по авторскому канону предполагаются **две декодируемые схемы: для русских слов и для латинских системных ID**. Конкретные нарисованные глифы ещё не утверждены, придумывать сейчас «тайный алфавит» нельзя.
2. **Зелёные ночные флуоресцентные надписи**: настоящая краска проявляется ночью естественным освещением, Монокль позволяет читать **локально в линзе и днём**. Такие надписи могут быть буквальным текстом, числом или руной; не нужно стилизовать их под музыку.
3. **Голубая скрытая музыкальная разметка**: **буквальные стрелки `↑↓←→`**, обычно видимые через локально перетаскиваемый Монокль. Нота на двери — знак музыкальной цели, а **не символ дополнительного алфавита**. Некоторые простые стрелки читаются и без Монокля.

**[Р] Механика журналирования:** обычное наблюдение сохраняет изображение/рисунок глифа без автоматического значения; при ручном сопоставлении букв/параметров игрок может видеть гипотезы, найденное верное системное имя можно копировать. Монокль даёт обход ручной дешифровки и в пределах линзы читает фактический текст. Не требовать зашифровать каждую надпись ради красоты. Использовать детерминированную таблицу `GlyphId` → кириллическая буква и отдельно `GlyphId` → латинская буква/цифра/подчёркивание для точных ID; никаких разных случайных алфавитов по биомам. Алфавит визуально рисуется позднее.

## 9. Критические QA и антизацикливание подсказок

**[12](12_V6_SIX_SCENES_SYSTEMIC_REDESIGN_2026-11-23.md#vi-руны-и-ночные-надписи-игрок-должен-находить-возможности-а-не-двадцать-записок) уточняет:** восемь цепочек знания W1–W8 важнее любого количества надписей; технические термины должны реально работать в системах, а бытовой текст может жить без кода.


1. **Ранний обычный игрок:** луга, Люма, лес, побережье, друзья и кафе работают без DEVELOPER, шифров, Монокля, музыкального хаба и открытия Пустоты.
2. **Юки:** из штатной адресной двери с правильным ID достижим только отдельный **Чёрный удалённый домик**; подарок Консоли не требует DEVELOPER/лесной консоли/управляемой загрузки; E033 остаётся другим объектом.
3. **Ори:** временно одолженный Каталог может создать настоящее существо; один проверенный заказ открывает подарок, а последующие предлагают игру без гринда. Поменять вид не стирает личность.
4. **Тоффи:** взгляд текущего героя запускает динозавра; закрытые глаза гасят погоню, `LOCKED` этого не делает; поражение честно восстанавливает игрока.
5. **Камера:** `CAMERA_MODE` имеет только `FOLLOW/LOCKED`; `FOLLOW_TARGET` отдельный и может менять автономное поведение Луны; III мост реагирует на внешний viewport.
6. **Fairy Realm:** эхо точно повторяет записанное движение/контакт, не дублирует уникальные артефакты и не ломает состояние при `SCALE`; понятный выход доступен без сложного пазла.
7. **Полные семейства:** 16 настоящих мостов, 5 проходов, 8 дверей, 6 foreground. После первого открытия закона хотя бы 3 другие проверки дают осмысленные отличающиеся результаты.
8. **Монокль:** настоящие зелёные тексты читаются ночью или локально днём через линзу; голубые стрелки преимущественно только через линзу; отдельные простые стрелки видны сразу.
9. **Шифры:** авторский алфавит для русских фраз и отдельная кодировка латинских полей, однозначная обратная расшифровка, никаких «рандомных рун ради рун». Найденное имя копируется в журнал и подходит к настоящему валидатору.
10. **Награда:** ни один из L-битов не требует трёх скучных одинаковых подвозов; сокращения реально остаются, а полученные знания применимы повторно.
11. **Реализация:** согласование данных до сборки `secret_features.json`, `MusicPhraseRegistry`, `InscriptionRegistry` и `TemporalEchoRecorder` является предложением устройства, НЕ утверждением о существовании этих файлов/классов.
