# 16 — Магия меняет окружение (graybox 0.15)

Игрок пользуется знакомыми огнём, холодом и молнией, а при экспериментировании с блоками CREATE / SHAPE / ELEMENT / BEHAVIOR / RELEASE / ON_HIT обнаруживает общие законы мира.

## MATERIAL — материал предмета

Материал можно изменять в инспекторе, не меняя тип объекта: деревянный холодильник остаётся холодильником.

| Материал | Горючий | Проводит электричество |
| --- | --- | --- |
| WOOD, FABRIC | Да | Нет |
| METAL | Нет | Да |
| STONE, ICE | Нет | Нет |
| ARCANE | Нет | Да |

Исходные значения: деревья — WOOD, холодильник — METAL, созданные предметы получают материал по общей таблице. Справочник качеств находится в scripts/core/material_profile.gd.

## Реакции окружения

**Огонь:** через некоторое время горящий объект может поджечь соседний горючий предмет. После обновления мира подсчитываются кандидаты — новый пожар не распространяется рекурсивно за один кадр. Количество новых и одновременно горящих объектов ограничено.

**Лёд:** попадание FROST создаёт временный ледяной участок на земле возле цели. Луна и существа на нём медленнее набирают и гасят скорость; ощущается инерция. Участок можно обновить новым попаданием, он исчезает со временем и виден как условная прозрачная зона.

**Таяние:** FIRE по объекту внутри ледяного участка растапливает этот участок. При сочетании с заморозкой реакция называется STEAM, при таянии одной поверхности — THAW. Другие участки не затрагиваются.

**Электричество:** цепные разряды перескакивают между ближайшими подходящими существами, учитывают проводимость материалов и постепенно теряют силу. Одна цель не получает удар дважды в одной цепи.

## Цепная молния: что уже работает

Стартовая молния (клавиша 3, ARC_BOLT) использует ON_HIT: CHAIN. После попадания разряд выбирает ближайшего ещё не поражённого *живого* персонажа и повторяет поиск уже от него. Базовый радиус следующего перехода 4.5 игровых единиц, максимум три дополнительных прыжка; урон затухает по коэффициенту 0.65 на каждом звене. Источник из METAL или ARCANE увеличивает локальный радиус на одну единицу (до общего предела).

Все изменения здоровья рассчитываются заранее и применяются как **одна транзакция**, поэтому при ошибке одного шага никто в цепи не получит частичное изменение. Статус SHOCK появляется после успешной транзакции. Для видимости Main создаёт короткие светящиеся дуги между целями на основе общего ArcaneLink.

Игрок может открыть конструктор клавишей B, разобрать заклинание и изменить режим ON_HIT, расстояние и число переходов. Параметры сохраняются в пользовательских рецептах. Эти числа пока временные и будут балансироваться при очной игре.

## Общая архитектура

- scripts/core/material_profile.gd — качества материала; parameter_registry.gd хранит редактируемое MATERIAL.
- scripts/core/elemental_status_service.gd — статусы, тики и распространение огня.
- scripts/core/surface_field_service.gd — временные ледяные зоны, сцепление и таяние.
- scripts/core/target_resolver.gd — поиск следующих целей электрических цепей.
- scripts/player_controller.gd, scripts/hackable_entity.gd и scripts/main.gd — движение и простая игровая визуализация.
- scripts/core/save_service.gd — хранение статусов, материалов и поверхностей в снимке мира.

## Тесты и границы текущего этапа

GitHub Actions выполняет tests/test_chain_lightning.gd, tests/test_environment_interactions.gd, tests/test_fire_melts_ice.gd и tests/test_main_integration.gd: проверяет материалы, перенос горения, устойчивость к бесконечным цепочкам, скольжение, сохранение и таяние льда. Реальный визуальный опыт на macOS ещё не оценивался.

Пока отсутствуют разрушаемость геометрии, физический пар, жидкая вода, тонкие различия между всеми материалами и финальная анимация стихий. Балансные числа остаются временными. Дальнейшие расширения должны пользоваться общими правилами, не создавать отдельный скрипт на каждый фаербол или предмет.
