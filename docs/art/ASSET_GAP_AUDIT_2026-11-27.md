> **[АВТОР §08.28, приоритет над длинными списками ниже]** Цельный румбокс включает значительную часть мелкого декора; самостоятельных предметов ограниченный выразительный набор, повторное использование, не каждый диван/подушка/мелочь. Добавить исследовательский уголок Они в Забытом крае, рисунок связей к пустому месту; точное расположение открыто. Руны только проявляются, не переводятся. Ведомость мебели — пул вариантов, не заказ всего списка.

## 2. Модульное тело и фауна
**[АВТОР]** Для каждого нового вида с ногами обязательна версия без ног; для крылатого без крыльев; для обоих — обе независимые вариации и комбинация. Если придаток отвечает за реальный изменяемый модуль, также предусмотрено его видимое отсутствие и установка. Это задача источника генерации, не попытка удалить пиксели из готового спрайта наугад.
| Семейство | Обязательные варианты / проверка |
|---|---|
| Лиса, заяц, кот, мышь, чернушка, альпака, ленивец, троллик, йетти, квадратная/обычная лягушка, черепаха, краб, аксолотль | Нормальное тело и без ног в нужных направлениях, крепления чистые; специфические ноги/лапки отдельным слоем там, где сохраняется форма. | Птицы, утки, бабочки, мотылёк, феи и крылатые виды из бестиария | Без крыльев, без ног если они есть, без обоих; отдельные крылья/слои спереди и сзади, idle/walk/fly/swim по фактическим способностям. Крылья не дают бесплатный FLY. |
| Скат, носитель Люмы, призрачный скат | Уникальные формы, купол/сиденья отдельно; плавники и полёт согласовать с нативной анатомией и реальным контрактом FLY, не механически срезать весь силуэт. Версия без изменяемой летательной части по утверждённой модели, без фантазийного переизобретения ската. |
| Слаймы, слайм-зайчик/слайм-лиса, улитка, осьминог, эмоты, невидимый гигант | Естественно безногая форма не требует удаления несуществующих ног. Проверять у каждого вида фактические способности, число конечностей и опоры; IS_ALIVE OFF не удаляет модуль. Выбор отображения по реальным модулям; технически проверить ON/OFF/remove/install и копирование, отсутствие остаточных деталей и изменения ID. Все существа одного масштаба P0, физическая высота/прыжок отдельно. Не удалять хвосты, щупальца или глаза только ради симметрии списка.

## 3. Общая библиотека (после P0)
**Материалы:** трава (светлая/цветущая), сухая тропа, камень, мокрый камень, лесная подстилка/мох, река/озеро/море с разными масками, песок сухой/мокрый, галька, городская плитка/брусчатка/газон, горная порода и бок острова, ранние материалы Забытого края. Края, углы, переходы только по графу реальной карты. 
**Природа:** деревья разных силуэтов (включая крупное дерево с отдельным корнем/окклюдером), кусты, папоротники, цветы, травы, грибы природные, лозы, ветви, пни только по месту, камни/арки/уступы, корни, ракушки и морские камни, кристаллы пола/стены/потолка с emission и вариантом оживления; дальние лесные массы, облака, острова, панорама Люмы. 
**Город:** цельные фасады ключевых домов, переиспользуемые фасадные детали, крыши/навесы/балконы/витрины, ступени/перила, фонари, клумбы/кашпо, урны/указатели/таблички номера/расписания как кандидаты бытового наполнения, открытая площадь, скамьи и зонты, сервисная галерея, скат/купол и станция. 
**Бытовые пропсы (кандидаты, не все обязательны):** кровать, матрас, подушка, одеяло; диван, кресло, табурет только в естественном интерьере (отменённый Q12 не возвращать), стул, стол, тумба, шкаф, книжный стеллаж, полка, комод, зеркало, коврик, шторы; лампа, настольный свет, часы, ваза, горшечное растение, книги/тетради/бумага/карандаши; холодильник, чайник, чашки/кружки, тарелка, ложка, вилка, поднос, кастрюля, хлеб/булочки/пончик, бутылки, продукты, коробки; дверные створки и ручки. По одному мастер-ассету на роль, материал/цветовые вариации по необходимости. Не нужен отдельный спрайт каждой ложки для каждой комнаты. Нельзя запекать hackable Entity в фон. Открытая/закрытая форма только у реально изменяемых/открываемых вещей.

- По каждому из действующих 16 артефактов: иконка HUD != мировой спрайт.
