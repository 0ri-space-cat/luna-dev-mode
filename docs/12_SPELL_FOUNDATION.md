# 12 — Первые заклинания, общий магический движок (0.8)

## Реализовано

**SpellService** хранит описания заклинаний как данные: ID, название, дальность, массив типизированных эффектов и метаданные каменной карточки (цвет камня / ID символа для будущего визуала). Нет индивидуальных скриптов на каждое заклинание.

При касте сервис определяет источник и цель по стабильным Entity ID, проверяет дистанцию и применяет эффекты через **EffectEngine → CommandProcessor**, сохраняя инициатора и источник вида spell:AWAKEN. Те же эффекты используются при открытом редакторе и через RuleEngine.

Три **демонстрационных** заклинания, доступных сразу:

| Клавиша | Имя | Эффект |
| --- | --- | --- |
| 1 | AWAKEN | IS_ALIVE := TRUE |
| 2 | PINKIFY | BASE_COLOR := розовый |
| 3 | QUICKEN | MOVE_SPEED += 1.2 (ограничен общим реестром параметров) |

На поле: обычный **ЛКМ** открывает окно взлома, **Shift+ЛКМ** применяет выбранное заклинание к объекту под курсором. Надпись в интерфейсе показывает текущее заклинание. Все три сейчас действуют в радиусе 11 игровых единиц. Ошибка дальности/цели показывается кратким сообщением.

**Это тестовые инструменты, не утверждённый финальный список заклинаний.** Тот же интерфейс SpellService.register_spell принимает пользовательские определения и несколько эффектов, что подготовит систему для будущего конструктора из карточек/блоков.

## Ещё не реализовано

- Пользовательский конструктор, редактирование эффекта/радиуса/триггера в игре, перетаскивание карточек.
- Каменные плитки с гравировками и рисованием своих символов (поля stone_color и symbol_id — только данные для будущего UI).
- Магическая стоимость, мана, cooldown, бросок снарядов, зоны/ауры, анимации взмаха/каста и заклинания сложной структуры.
- Сохранение пользовательских заклинаний между забегами.
- Атомарность заклинаний с несколькими эффектами: сейчас применяются по очереди; при ошибке частичное применение возможно. Это нужно решить до полноценного редактора пользовательской магии.
- Свободная цель у Луны, перки и взаимодействия с артефактами.

## Проверка в CI

- tests/test_main_integration.gd — проверка взаимодействия полной сцены, сохранений направленных отношений, журнала Луны и магии.
