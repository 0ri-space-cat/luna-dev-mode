# 07 — Первая играбельная версия (Godot graybox 0.1)

## Что добавлено

Это **самый первый технический прототип**, созданный для проверки петли «выбрать объект → остановить мир → изменить параметры → наблюдать последствия». Он не является реализацией всей архитектуры из docs/05.

- Минимальный проект Godot 4.3+ в режиме GL Compatibility для проверки на Mac.
- Ортографическая 3D-камера сверху под углом; пастельные цвета и примитивные фигуры.
- Луна — процедурный placeholder с шляпой; перемещается по WASD или стрелкам.
- Два дерева и холодильник; выбираются кликом мыши посредством физического луча.
- Базовый редактор пяти параметров с английскими именами капсом: `IS_ALIVE`, `HEALTH`, `MOVE_SPEED`, `SCALE`, `BASE_COLOR`. Значения логических полей отображаются как `TRUE/FALSE`.
- Мир замирает во время редактирования (SceneTree.paused); появляется лёгкая бирюзовая пелена. UI продолжает работать. Полный глитч и звук — позже.
- `SHOW_HINTS: TRUE/FALSE` включает или скрывает короткие русские пояснения под каждой строкой параметра; изначально подсказки выключены.
- `IS_ALIVE: TRUE` показывает ноги и запускает самостоятельное случайное движение. Дерево тоже можно оживить.
- Простая модель EntityRecord хранит исходную категорию и набор значений, не привязанный к оформлению.

**Не реализовано:** сохранения, Undo, полноценный ParameterRegistry, CommandProcessor/ChangeProvenance, перки, правила, заклинания, артефакты, сюжет, анимации, мета-секреты, портал, интерактивные границы карты, пользовательские гравировки, поведение NPC и финальный внешний вид. Они описаны в docs/01–06 и не должны считаться забытыми.

## Запуск на macOS

1. Установить Godot 4.3 или новее, если он ещё не установлен. Исходники проекта не требуют плагинов и сторонних 3D-ассетов.
2. Скачать репозиторий (Code → Download ZIP) или выполнить команду клонирования: git clone https://github.com/0ri-space-cat/luna-dev-mode.git.
3. В Godot Project Manager выбрать Import → файл project.godot из папки репозитория.
4. Открыть проект и нажать F5 (Play Project).
5. Ходить WASD/стрелками. Кликнуть по дереву или холодильнику. В редакторе менять `BASE_COLOR`/`SCALE`/`HEALTH`/`MOVE_SPEED` и установить `IS_ALIVE: TRUE`. Переключатель `SHOW_HINTS` показывает краткие русские описания. Нажать кнопку закрытия или Esc: мир снова движется.

Если нажать ЛКМ на пустом месте, ничего не произойдёт. Редактор предназначен только для тестовых объектов.

## Известные ограничения и проверки

- Код отправлен в GitHub, но **автоматического запуска Godot в текущей рабочей среде не было**: Godot CLI не установлен. Первый реальный запуск и ошибки парсера необходимо проверить на Mac.
- Временная графика: пока без толстых контуров, финальных анимаций, постерного стиля и пиксельного шрифта.
- Ножки сущностей пока простые геометрические прямоугольники.
- Случайное блуждание ограничено приблизительными координатами площадки и ещё не имеет навигации вокруг препятствий.
- Изменения размера, цвета и скорости происходят немедленно; HP пока демонстрационный параметр без боевой механики.
- Поведение объектов обрабатывается в _physics_process; во время редактора пауза останавливает движения, пока всегда активный CanvasLayer показывает UI.

## Следующие технические шаги

1. Прогнать проект в настоящем Godot и исправить ошибки запуска.
2. Выделить ParameterRegistry и CommandProcessor с атрибуцией автора изменений (для Юки), историю изменений и Undo.
3. Оживлённым предметам дать универсальные цели (патрулировать / следовать / нападать).
4. Добавить окно правил и короткую цепочку эффектов; затем попробовать «записать взлом как заклинание».
5. Проводить визуальную стилизацию после проверки работающего core loop.
