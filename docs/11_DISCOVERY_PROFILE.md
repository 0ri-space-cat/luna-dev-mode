## Реализовано

- **ProfileService** хранит категории объектов, которые Луна хотя бы раз открывала в редакторе взлома, и имена конкретных параметров, которые игрок действительно изменял.
- **J** открывает небольшой список уже исследованных категорий и параметров. Это временная форма дневника, пока без финального оформления и полноценной системы секретов.
- Данные хранятся в **user://luna_profile_v1.json**, независимо от текущего мира, в **user://luna_world_v1.json**.
- Исследованные параметры остаются в профиле между перезапусками и будущими забегами; загрузка старого мира не откатывает знания игрока.
- Вся запись/чтение JSON использует общий модуль JsonStore, а не отдельный код для каждого файла. Запись сначала идёт во временный файл с последующей заменой.
- Запись идёт при новом открытии и изучении, а также на выходе. Повторные открытия уже известных параметров не переписывают профиль.

**Знания игрока** (какие виды и свойства он исследовал) отделены от **фактов текущего мира** (цвет, скорость, отношение холодильника к дереву). Эту границу соблюдать при добавлении New Game и нескольких миров.

## Что ещё не добавлено

- Нет журнала сюжетных секретов, выводов Луны, гипотез и «идей для экспериментов». Система перков отменена и её реализовывать не требуется.
- Не все события отмечаются как открытия: сейчас только взлом/изменение параметров именно Луной. Спеллы, экспериментальные аномалии, Юки и социальные тайны будут подключаться через общий EventBus после дизайна типов открытий.
- Записи профильных данных не дают скрытых игровых баффов, ворот прогрессии или необоснованных знаний о мире. Это журнал обнаруженного.
- Вспомогательное окошко J — техническая заготовка. Финальный стиль, навигация и комментарии Луны позднее.

## Проверки

tests/test_profile_service.gd: повторные открытия не дублируются, профиль отдельно сохраняется на диск, восстанавливается после нового запуска, неверные версии и некорректный JSON отклоняются без потери уже загруженных данных. Общие тесты сохранения мира также проходят через JsonStore.
