Личный инструмент принадлежит единственному герою, а **профиль активируется через DEVELOPER** и защищённый портрет HUD.

## Единая карточка артефакта для контента

Каждый из шестнадцати содержит `artifact_key`, `entity_id`, `region_id`, `owner_profile_id|null`, `unique_state`, `pickup_policy`, `effect_component`, `initial_discovery`, `save_policy`, `recovery_policy`, `alt_uses` (минимум два реальных взаимодействия), `allowed_targets`, `qa_test_ids`. Только после проверки работающего Godot объекта статус меняется с **DESIGN_READY** на **IMPLEMENTED**.

**Первая демонстрация не обязана давать предмет.** Для шести личных инструментов игрок сначала наблюдает персонажа, а позднее управляет им. Для самостоятельного объекта игрок вправе игнорировать его и всё равно пройти обычную дружескую историю.

## Первые три испытания жизнеспособности

1. Камера доступна раньше моста, живые следы невидимых заметны без подсветки, а Тоффи живёт за пределами собственной сценки.
2. Юки программирует город, Ори создаёт питомца, кафе существует независимо от числа знакомых; вернувшийся игрок видит изменённое поведение объектов.
3. С двумя палочками работает DEVELOPER, а Свиток **ни разу** не появляется даже как отсутствующая кнопка; новая собственная команда в палочке даёт реальную составную магию.
