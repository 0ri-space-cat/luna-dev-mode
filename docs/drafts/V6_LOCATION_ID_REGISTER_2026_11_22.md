**Дата:** 22 ноября 2026. **Статус:** сценарная согласовательная таблица, а не доказательство, что каждый адрес уже реализован в Godot. ## Типы имён

- **LOCATION_ID:** строка настоящего адресуемого внутреннего пространства/региона, если он зарегистрирован в мире. Возникает в HUD при реальном входе, но для непрерывного региона не всплывает каждые несколько шагов.
- **FEATURE_ID / BEHAVIOR:** имя объекта, физического закона или водного источника **внутри** локации, не новый адрес сам по себе.
- **SYSTEM_TARGET / GLOBAL_VALUE:** объект или значение уровня движка, **не принимается обычной дверью** автоматически.
- **CANDIDATE:** полезная рабочая строка из сценария, не объявленная автором окончательной и не гарантированно существующая в коде.

## Важные инварианты для кодового реестра

1. Один настоящий ID должен указывать на **одну определённую логическую сцену**; переиспользование одного вида стен для двух разных мест не означает общий ID.
2. При входе через адресную дверь нужен **действительный ReturnAnchor** и безопасная точка назначения. Нельзя появиться в потоке водопада, пустой коллизии, бесконечном падении или теле клона.
3. Раннее знание имени внутренней комнаты не требует сюжетного флага её «официального открытия», **но** валидатор типов не принимает глобальный переключатель WHITE_VOID как локальный дверной адрес.
4. Большая карта и Пиксельный глобус показывают доступную картографию, не автоматически все скрытые узлы и их внутренние адреса.
5. Первый вход в настоящую новую сцену показывает ID внизу HUD, повторный вход тоже; непрерывное движение внутри одного ID не вызывает десяток плашек.
6. **Что ещё открыто:** фактические имена файлов/сцен Godot, примыкающие ReturnAnchor, физическая топология разветвлений, типы локаций с доступом по двери, реальные конечные имена глобального переключателя леса, размер/точка генерации клона и безопасные позиции входа за каскад.

## Быстрая приёмка

- Поиск по активным сценариям не должен показывать ET_WATERFALL_BEYOND_THIRD_BRIDGE как актуальный ID.
- При входе в пещерное Озеро HUD показывает ET_DUPLICATE_LAKE_CAVERN, а не ET_DUPLICATE_LAKE.
- Чёрный загрузочный карман не называется Белой Пустотой.
- Лесной терминал может направить напрямую в Белую Пустоту **по настоящему знанию даже с PLAYFUL**.
- Оконный GAME_FRAME требует DEVELOPER в оконном режиме, но не предыдущее посещение мостового убежища.
- Дверь не создаёт копии NPC, не размножает уникальные инструменты, сохраняет возвращение и нормальные ID.
