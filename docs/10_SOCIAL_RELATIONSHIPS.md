## Уже реализовано

**RelationshipService** хранит раздельные связи по стабильным ID сущностей. Например, TREE → FRIDGE = HOSTILE и FRIDGE → TREE = FRIEND — законное состояние. Отношение NEUTRAL означает отсутствие связи. Значения: NEUTRAL, FRIEND, HOSTILE, AFRAID. Для разработчика есть валидируемый API set_attitude, get_attitude, export_data, import_data и отдельный аудит со сведениями об авторе/источнике.

**BehaviorBrain** в режиме AUTO выбирает действие по отношению к ближайшей цели из TARGET_GROUP (вместо жёсткой привязки всех реакций к Луне). Соответствие: FRIEND → FOLLOW; HOSTILE → CHASE; AFRAID → FLEE; NEUTRAL → WANDER. Игровой параметр LUNA_RELATION синхронизируется с направленной связью выбранного объекта → Luna. Отношения других пар пока задаются через внутренние API или типизированные правила; полноценная визуальная панель социальных связей впереди.

**EffectEngine** принимает SET_RELATION (subject_id, target_id, value). RuleEngine также может выполнять этот эффект. Изменения генерируют событие relationship.changed. Напрямую нельзя установить ссылку на несуществующую цель или недопустимое отношение через EffectEngine.

**SaveService** теперь записывает отношения в том же версионированном JSON снимке мира. Старые сохранения без этих данных читаются: LUNA_RELATION каждого объекта восстановит связи с Луной. Данные графа проверяются до применения мира; при некорректном отношении загрузка отклоняется без частичного изменения мира.

## Чего пока нет

- Отдельного игрового UI для «этот холодильник любит конкретно вот это дерево»; пока есть LUNA_RELATION в общем редакторе и системный API для прочих пар.
- Доверия/силы отношения по числовой шкале, фракций, групповых связей, эмоциональных аур Леи, диалогов, боевой системы и NPC.
- Команд Undo/Redo конкретно для социальных связей. Их аудит отделён от ParameterCommandProcessor. В конечном итоге всё должно проходить общий расширенный CommandProcessor.
- Взаимодействий через дистанционные вызовы (помощь союзнику, реакция на вред, защита) — это будущие события/правила.

## Проверка
