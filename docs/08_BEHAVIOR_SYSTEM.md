# 08 — Универсальное поведение существ (prototype 0.3)

**Статус:** реализован первый прототип; поведение и ощущение движения нужно проверять в GUI на Mac. Реализация покрывается headless Godot CI.

## Уже реализовано

- BehaviorBrain — общая логика выбора действия и плавного поворота, независимая от визуальных моделей.
- WorldRegistry — реестр объектов со стабильными ID и слабыми ссылками на Node, поиск ближайших целей по типу и дистанции.
- ParameterRegistry понимает enum: все значения BEHAVIOR_MODE, TARGET_GROUP и LUNA_RELATION задаются централизованно, а инспектор автоматически строит выпадающие списки.
- HackableEntity превращает решение мозга в движение CharacterBody3D с ускорением, сглаживает вращение корпуса, анимацию прямоугольных ног и реакцию на столкновения.
- Деревья и холодильники используют один код поведения и отличаются только стартовыми параметрами/моделью.

## Новые переменные инспектора

| Название | Значения | Зачем |
| --- | --- | --- |
| IS_ALIVE | TRUE/FALSE | Жизнь отдельно от категории предмета |
| AI_ENABLED | TRUE/FALSE | Возможность самостоятельно принимать решения |
| BEHAVIOR_MODE | WANDER / FOLLOW / CHASE / FLEE / IDLE / AUTO | Стратегия движения |
| TARGET_GROUP | LUNA / ANY / TREE / FRIDGE | Класс объектов, среди которых выбирается ближайший |
| LUNA_RELATION | NEUTRAL / FRIEND / HOSTILE / AFRAID | Отношение к Луне в режиме AUTO |
| SENSE_RANGE | 2.0–25.0 | Радиус поиска целей |
| FOLLOW_DISTANCE | 1.0–7.0 | Дистанция остановки при FOLLOW |
| MOVE_SPEED | 0–5 | Скорость предмета |

Остальные поля — HEALTH, SCALE, BASE_COLOR — сохраняются. Все изменения проходят через CommandProcessor: авторство, аудит, Undo/Redo.

### Примеры ручной проверки

1. Оживить холодильник. При WANDER он бродит более плавно, с короткими паузами и поворотами, чем в версии 0.2.
2. Выбрать BEHAVIOR_MODE: FOLLOW, TARGET_GROUP: LUNA — холодильник подходит к Луне, но старается держать FOLLOW_DISTANCE.
3. Поменять BEHAVIOR_MODE: FLEE — убегает от Луны, пока не окажется вне опасной дистанции.
4. Поставить BEHAVIOR_MODE: AUTO, LUNA_RELATION: FRIEND — следует за Луной; HOSTILE — преследует; AFRAID — убегает; NEUTRAL — бродит.
5. В дереве выбрать BEHAVIOR_MODE: CHASE и TARGET_GROUP: FRIDGE — дерево ищет холодильник, а не Луну.
6. AI_ENABLED: FALSE прекращает автономное движение, не отключая IS_ALIVE.
7. История изменений доступна игровому движку, но кнопки Undo/Redo убраны из окна параметров. Категория TREE / FRIDGE не меняется.

### Что ещё отсутствует

- CHASE пока означает приближение к цели; урон, нападение и боевую анимацию добавим позже.
- AUTO пока принимает решение только из LUNA_RELATION. Полноценные отношения между произвольными парами сущностей и фракции ещё не реализованы.
- Навигация пока локальная: нет NavMesh, сложных путей вокруг зданий и полноценного обхода препятствий.
- Плавность холодильника улучшена на уровне кода, но ещё нуждается в зрительной оценке и подборе таймингов.
- Знания о 2D/3D и изменении положения инспектора сохранены в docs/01, docs/04 и docs/06; пока отложены до готового каркаса.
- События и эффекты реализованы в 0.4, сохранение мира — в 0.5. См. [09](09_SAVE_AND_EVENTS.md).

## Для будущих моделей

Не создавать по новому AI-скрипту под каждую категорию объектов. Систему расширять через BehaviorBrain, TargetFilter/WorldRegistry, ParameterRegistry и новые действия/условия. Свойства тела (физика) и свойства поведения (brain) должны оставаться независимыми.

После устойчивого 0.3 — RelationshipService для отношений между любыми объектами, RuleEngine с реакциями WHEN → IF → DO → TARGET, общий EffectEngine. Избегать перехода к косметической полировке раньше, чем заработают эти системы.
