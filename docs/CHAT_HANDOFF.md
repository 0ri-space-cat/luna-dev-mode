# LUNA: Dev Mode. Переход для следующего чата

**С 23.11.2026 этот handoff заменён единым [производственным мануалом](manual/00_LUNA_PRODUCTION_MANUAL.md).** Старый длинный handoff оставлен в Git history: он содержал множество накопленных, в том числе несовместимых и отменённых, версий. Не продолжать обсуждение по старым вводным и не писать следующий файл-пересказ.

## Что делать следующей модели

1. Открой [Мануал LUNA](manual/00_LUNA_PRODUCTION_MANUAL.md), прочитай §00, §01, §10–§12.
2. Продолжай указанную там **незавершённую задачу этапа 1** (4 маршрута игроков, предложение скрытого слоя невидимой экологии и варианты истории Тоффи). Сначала различай авторское решение и новое предложение.
3. Для спорных деталей открой оригинальный [канон](canon/00_START_HERE.md), [единый сценарий](scenario/00_LUNA_V6_INTEGRATED_WORLD_SCENARIO_2026-11-22.md) и соответствующий Godot-код.
4. **Обновляй существующий тематический раздел того же мануала**, его журнал и точку продолжения. Не создавай ещё одну конфликтующую «финальную Библию».

Проект: уютная современная фантастическая Этерния, настоящая магия и хакинг, милые и странные существа, метроидвания, знание вместо XP, постепенные метаоткрытия. Старые бытовые задания уже сняты; не размножай квесты и зверей ради количества.
