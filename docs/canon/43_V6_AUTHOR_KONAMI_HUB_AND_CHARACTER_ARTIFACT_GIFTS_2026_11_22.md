Они присутствует в обычном мире/кафе, но управляемый профиль и оригинал Призмы открываются только в далёком убежище изнанки; искусственно отключать её врождённый навык не нужно. **Лея видит эмоциональные ауры врождённо** даже после передачи Сердца. Дополнительные герои преимущественно косметические, общий журнал и подсказки параметров меняют стиль, важные артефакты получают небольшие необязательные пазлы и награды без ключей к метафиналу.

**Дата:** 22 ноября 2026. **Статус:** прямые решения автора из очередного обсуждения с явным отделением пока не выбранных частностей. **Высший приоритет при противоречии** с прежним запретом подарков в главах 25/32/35/40 и сценарием I–IX, а также с черновиком `docs/drafts/V6_CHARACTER_GIFTS_VS_HACK_TOOLS_REDESIGN_PROPOSAL_2026_11_22.md`. Главы 41–42 и иные утверждённые законы продолжают действовать, где нет прямого противоречия. **Только решение дизайна, не доказательство имплементации в Godot.**

## 1. УТВЕРЖДЕНО АВТОРОМ: мелодия Конами — один из центральных музыкальных секретов

- Последовательность на свирели **строго восемь стрелок**: **`↑ ↑ ↓ ↓ ← → ← →`**, технически **`[UP, UP, DOWN, DOWN, LEFT, RIGHT, LEFT, RIGHT]`**. **Не добавлять B/A** из полной исторической версии сочетания.
- Это **реальная рабочая мелодия**, которая **переносит Луну в ранее утверждённый музыкальный хаб телепортов между биомами**. Центральный узнаваемый секрет, а не декоративная отсылка без эффекта.
- **Любой игрок, знающий последовательность, может сыграть её немедленно, как только обладает свирелью.** Не нужны «выученная мелодия», найденный листок, посещённая птичка, прочитанный Монокль, обязательный квест или условие прежнего посещения хаба.
- **В мире обязательно должна существовать хотя бы одна реальная обнаруживаемая подсказка**, показывающая эту последовательность обычными символами стрелок (по закону главы 42: видимая открыто или через голубую флуоресценцию в линзе Монокля в зависимости от размещения). Таким образом, ретро-игрок узнаёт отсылку, остальные разгадывают её по найденной записи.
- Дополнительные музыкальные мелодии для нотных дверей, прямых секретных телепортов и других эффектов сохраняются. Нельзя свести весь игровой нотный язык к Конами/трём мелодиям.
- Не выдавать сам хаб за раскрытие всех неизвестных/тайных регионов: **какие направления в хабе уже открыты и как устроена география хаба остаётся открытым дизайнерским вопросом**.

## 2. Новая принятая системная граница: три самостоятельные категории

**(A) АРТЕФАКТ** — физический уникальный предмет, один оригинал с определённым `Entity ID`, владелец которого может поменяться. **16 именованных позиций остаются; Свиток по-прежнему удалён.** Среди них есть шесть подарков друзей. Предмет сохраняет собственную механическую функцию, его подаренность сама по себе не делает новую копию.

**(B) ЛИЧНЫЙ ИНСТРУМЕНТ ВЗЛОМА** — у каждого из **семи** играбельных персонажей есть **собственная уникально оформленная палочка под стиль/вайб героя** либо органичный её эквивалент. Все герои могут обычным способом **взламывать существ и предметы**, пользоваться общей базой семи вкладок и физическими игровыми операциями. Для Они уже существует выразительная кибернить с флешкой; при производстве это может быть её собственный «палочкоподобный» взламывающий инструмент, **не стоит вырезать установленный жест ради формального одинакового деревянного жезла**. Реализация и точная форма каждой палочки пока не определены. Персональные палочки находятся **вне 16 уникальных артефактов**; не являются копиями отданного дара.

**(C) ЛИЧНЫЕ СВОЙСТВА/ХАРАКТЕР** — за героем сохраняются только явно указанные врождённые особенности и характерные реакции. **Отменено предложение вводить каждому персонажу скрытые эксклюзивные редактируемые параметры, вкладки или разрешения.** Пользователю не нужно переключаться на другого героя, чтобы получить обычное редактирование живого существа. Универсальные семь вкладок редактора сохраняются.

**Отмена старого запрета:** прежняя фраза глав 25/32/35 «личные артефакты никогда не передавать Луне после дружбы» **устарела**. Теперь после **необязательной личной ветки** герой может отдать **свой настоящий артефакт-оригинал** Луне. Получение подарка сразу открывает обычный скин соответствующего героя; **DEVELOPER не требуется для обычной смены открытых скинов**. DEVELOPER сохраняется для глубокого TAB-взлома системных HUD-целей. Последующее прямое решение автора: **общий инвентарь и общий уровень доступа `player_wand_access_level` у всех игровых палочек**, при реальных отдельных физических копиях из Озера.

## 3. Подарки: УТВЕРЖДЁННЫЕ АВТОРОМ назначения

| Кто | Какой из существующих 16 артефактов отдаёт Луне | Что делает после передачи | Что сохраняется у героя |
|---|---|---|---|
| **Юки** | `YUKI_CONSOLE` — **консоль/клавиатура** | Все ранее подтверждённые режимы КАРТОЧКИ/МИР/КОД, библиотека, глобальные скрипты, действительные связи событий, исполнение программ и безопасный выключатель | Собственная индивидуальная палочка для обычного взлома, знание системы, характер Юки и возможные реплики |
| **Тоффи** | `TOFFI_LANTERN` — **фонарь** | Включаемая/выключаемая видимость **только невидимых существ** у носителя; прежний взломанный режим невидимости для других существ должен быть согласован с новым носителем (см. ниже) | **Всегда видит невидимую фауну даже без фонаря**, собственная палочка |
| **Лея** | `LEIA_HEART` — **Сердце эмпатии** (новое отображаемое имя; сохранять stable key ради сейвов) | **Видны эмоциональные ауры существ**; при направленном взаимодействии Сердцем с существом можно **открыть/редактировать непосредственно параметры эмоций этого существа**. Инструментальное окно/режим связан с Сердцем, доступен Луне; конкретная детализация UI впереди | Звери **врождённо обожают Лею и набегают/обступают её**; **эмоциональные ауры она тоже видит врождённо без Сердца**, собственная палочка |
| **Мия** | `MIA_POTION` — **уникальное бесконечно используемое зелье** | Предмет **многоразовый/неисчерпаемый**, его эффект можно **перенастраивать взломом**, как и режим применения обычное/бросок `NORMAL/THROWABLE`; не создавать новую бутылку с новым уникальным ID за каждое применение | Собственная палочка и характер Мии, её бытовые опыты/понимание алхимии, **без второго такого же универсального артефакта** |
| **Ори** | `ORI_CATALOG` — **Каталог существ** | Луна может **спавнить новых реальных существ**; уже утверждённое изменение вида существующей Entity с сохранением её ID/памяти/характера тоже остаётся | Собственная палочка, личная история и интерес Ори к существам; его обычный редактор не копирует все функции подаренного Каталога |
| **Они** | `PRISM` — **Призма** | Даёт второй способ видеть уже существующую **голубую геометрическую изнанку**; после взлома `TRANSPARENT` накладывает её контуры на обычный красочный мир, **без автоматического изменения коллизии** | **При закрытых глазах Они видит изнанку сама, без артефакта**; её кибернить/собственный инструмент взлома, независимый от Призмы |

**Призма и сцена Они: авторский ориентир (не утверждённые диалоги).** Призму Луна получает **после самостоятельного открытия закона проекции палочки**: физически оставить палочку и выйти за радиус её проецирования, увидев голубую геометрию. В одном из настоящих **убежищ, связанных с изнанкой**, Луну может ждать Они, которая тоже её изучает. Узнав, что Луна разобралась в этом законе, Они дружески отдаёт Призму как удобный способ видеть структуру мира: смысл возможной реплики «О, значит, ты тоже узнала о скрытой геометрии Этернии? Держи, с ней будет проще её видеть». **Это интонация автора, не окончательная дословная реплика или утверждённый адрес сцены.** Прежнее местоположение Призмы как свободного артефакта за изнаночным проходом **заменено**: теперь оригинал может **находиться у Они в таком убежище**, а не одновременно лежать вторым экземпляром в тайнике. Путь к ней должен оставаться **физически знание-зависимым**, без обязательного чекбокса `has_seen_underside`. Детали согласования персональной ветки Они и момента подарка пока требуют постановки: новая сцена не должна создавать принудительный ключ к Белой Пустоте.

**Цифровой глаз отдельно:** `DIGITAL_EYE` по-прежнему самостоятельный №15, очень глубокий секрет Белой Пустоты, **не стартовая вещь Они и не её подарок**.

## 4. Важные уточнения к функциям / старые запреты сняты

1. **Сердце Леи:** правило «обычный кулон, никаких аур и редактирования эмоций через предмет» отменено. Отображаемое имя **«Сердце эмпатии»**, функции артефакта: **эмоциональные ауры + прицельная работа с параметрами эмоций существа**. **Лея дополнительно врождённо видит эмоциональные ауры без Сердца; уникальная восьмая вкладка профиля по-прежнему отменена.** При необходимости интерфейс Сердца открывает специализированный инструментальный редактор эмоций любому владельцу, а обычный редактор семивкладочный для всех. `LEIA_HEART` временно сохраняется для совместимости данных.
2. **Фонарь Тоффи:** теперь важна применимость фонаря Луной. Его функция не включать все секреты мира или изнанку, а только **невидимых существ**. Старое свойство взлома `INVISIBLE_TO_OTHERS` было зафиксировано **для Тоффи**. Передача вещи Луне требует определения области действия. **На рассмотрении:** привязать взломанное свойство к **текущему носителю**, чтобы оно оставалось осмысленным и у Луны, но **не объявлять это утверждённым дословным решением автора**, пока не обсудили.
3. **Зелье Мии:** предусмотреть бесконечное использование и редактирование самого зелья; расходуемым может быть **эффект/заряд/анимация применения**, но **не окончательное исчезновение уникального оригинала**. Точная физика броска и возвращения многоразового сосуда подбирается при реализации, не создавать скрытых копий `MIA_POTION` с той же идентичностью.
4. **Юки:** отдельная личная палочка позволяет ей продолжать **обычный взлом** после отдачи консоли. **Её знание мира и характерные контекстные комментарии** — автору интересно, особенно при глобальной лесной консоли и обычном хаке («вот это лучше не нажимай»). **Пока на рассмотрении**, насколько Юки даёт игроку **подсказки реальных параметров**, и понимает ли она **рунические записи без Монокля**. Не внедрять автоматическую расшифровку всех рун, не разглашать неизвестные secret-ID, не превращать Юки в требуемого спойлер-оракула без отдельного решения.
5. **Тоффи/Они/Лея:** у Тоффи постоянное видение невидимых, у Они видение изнанки с закрытыми глазами, у Леи **врождённое видение эмоциональных аур и любовь животных**; ни одна из этих природных особенностей не теряется при дарении физического артефакта. Они **подготавливается как профиль только после секретного убежища**, обычное кафе не требует Призмы.
6. **Другие герои:** не добавлять ранее предложенные ассистентом персонажные поля `TARGET_EVENT`, `SPECIES_ID`, `VISIBLE_TO`, `EFFECT_DURATION`, редкие «уникальные» вкладки или новые права просто ради непохожести. Обычный редактор существ и предметов **всем**.

## 5. Архитектурное разделение для реализации (ПРЕДЛОЖЕНИЕ по устройству, не имена утверждённых классов)

- `ArtifactEntity`: существующий предмет из 16, один уникальный origin ID, `held_by`/позиция. `GiftTransfer` меняет **владельца того же оригинала**, не вызывает spawn дубликата и сохраняет историю; самостоятельная физика Озера Дубликатов остаётся отдельным реальным законом, создающим новые Entity ID.
- `PersonalHackTool`: один постоянный инструмент взлома у каждого играбельного героя, **не считается артефактом из 16** и не телепортируется Луне при переключении. Общее API редактирования реальных Entity и защита прав; разные визуалы/анимации/звучание. Все управляемые палочки **пользуются единым заработанным `player_wand_access_level`**; успешный взлом копии любого скина до DEVELOPER в Озере открывает его другим скинам без нового озёрного эксперимента. Уточнить отношение к `projection_field`: только надлежащие физические палочки должны поддерживать закон голубой изнанки, а инструменты друзей не должны незаметно стирать поле Луны или спаунить копии.
- `CharacterInnateTraits`: природное восприятие Тоффи, видение Они при закрытых глазах, привязанность животных к Лее; **без** отдельных персонажных дополнительных системных полей редактора.
- `HeartEmotionsTargetedAction`: при активном Сердце показывает ауры для валидных существ и открывает одобренный набор эмоциональных параметров **на целевой физической сущности**. Изменение проходит через ту же модель реальных полей/Undo и права; не создаёт второго «магического мира эмоций».
- `YukiContextHint` — **неутверждённая возможность UX**, контекстная эмоциональная реплика по известным системе состояниям, без принудительного туториала или разглашения секретных ID. Осмысленное игровое поведение Юки можно сделать без дополнительных прав.
- Музыка: `MusicPhraseRegistry` связывает `[UP, UP, DOWN, DOWN, LEFT, RIGHT, LEFT, RIGHT]` с **`HUB_ACCESS`**, телепортацией в существующий зарегистрированный настоящий location ID музыкального хаба (сам точный ID ещё не утверждён). Запись-подсказка настоящая Entity/feature в мире, обычные видимые стрелки либо голубые стрелки через Монокль. Исключить ошибку преждевременного принятия более короткой фразы, если она совпадает с префиксом Конами. Без требования `learned_konami`.
- Изменения одобрены на **уровне сценария/системного дизайна**; кода Godot, сцен, анимаций и тестов эта запись не создаёт.

## 6. Что сохранить без изменений

- **16 артефактов, без Свитка.** Свирель и личные палочки находятся за пределами 16.
- **7 реальных играбельных героев**, не клоны при переключении, живут автономной жизнью.
- Личные ветки необязательны, обычные маршруты Этернии и метапуть не требуют 6 подарков; после побочки игровые скины сразу выбираются обычным меню; DEVELOPER нужен только для глубокого системного TAB-взлома HUD.
- Сохранение физического свойства голубой изнанки, самостоятельный тайник/контекст знания, Призма как **удобный второй способ**, а не первичный ключ.
- Консоль Юки, Каталог Ори и все прочие артефакты сохраняют прежние подтверждённые сильные функции; новые версии их не урезают ради баланса.
- **Никакого принудительного класса героя с запретом на взлом существ**: это прямо противоречит новому желанию автора и усложнит постоянные эксперименты.
