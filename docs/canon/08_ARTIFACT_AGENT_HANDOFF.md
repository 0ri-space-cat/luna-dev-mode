## 2. Утверждённые автором изменения — НЕ переосмыслять

- **Руна** (`ART-LU-01`): небольшой магический камень с символом, не офисная печать.
- **Призма** (`ART-GL-04`, `PRISM`): **простой цельный прозрачный треугольный кристалл** с сиренево-бирюзовыми переливами; внутри маленькая плоская картинка/силуэт мира. Без иглы, булавки, ручки и механизма. **Даёт поздний hands-free доступ к той же светло-голубой изнанке, что открывается палочкой**; никаких новых слоёв реальности, отдельного рендера или переноса объектов. Раннее получение возможно при знании секрета WORLD 00. Утверждённый PNG-мастер не перегенерировать.
- **Песочные часы** (`ART-GL-01`): обычный легко узнаваемый сказочный силуэт песочных часов, фиолетово-бирюзовый парящий песок. Управляют `WORLD_TIME_SCALE`, ускорением/замедлением/паузой **ВСЕГО игрового мира** (с безопасным освобождением держателя и UI от паузы). Никаких будильников.
- **Компас** (`ART-GL-05`): золотой волшебный компас; меняет направление и силу гравитации в ограниченной зоне. Заменил старый **A02 — локальный Якорь времени**, который не должен генерироваться как часть актуального набора.
- **Свиток** (`ART-GL-02`) заменил кассету; **Зеркало** (`ART-GL-03`) заменило перископ. У Юки **Скоба**, а не степлер. Остальные короткие названия и формы — ровно из каталога.
- Из предметов убрать офисные элементы, современную USB-электронику, ножки/лица без надобности, «случайные волшебные механизмы». Результат должен сразу читаться как руна, клубок, губка, фонарь, песочные часы, призма.
- **Обычная палочка Луны** уже умеет менять маршруты **одного NPC** и адреса дверей. Клубок Юки показывает пути наглядно и редактирует несколько точек/маршрутов быстрее; он не является обязательным разрешением на сам принцип изменения NPC-маршрутов.
- **Апгрейд палочки:** игрок делает в озере копию, берёт **копию**, оставляет **оригинал на земле**, и **копией взламывает оригинал**, повышая `SCAN_DEPTH`, `TARGET_RANGE` и прочие поля, вплоть до `DEVELOPER_MODE`. Не использовать устаревшую обратную последовательность.
- Старые N-01…N-04 детективные квесты Óни отменены; у неё только N-01 «Гонка с эхом» и N-02 «Парад на опережение» с временными траекториями.

**Отдельное правило геймдизайна:** система перков, XP/LEVEL и покупаемых навыков **отменена**; не возвращать её при разработке артефактов и персонажей. **Глубокая эмпатия Леи** — встроенное с начала зрение потребностей животных, причин эмоций и направленных связей. **Луна** сопереживает по характеру и может рано найти **Кристальное сердце `ART-GL-06`**, дающее лишь тип/цвет и силу эмоции. Её палочка меняет простые параметры настроения без глубокого анализа причин. Ни один герой не покупает эмпатию за XP. Артефакты дают операции над миром, не проценты бонусов.

## Новый рабочий порядок от 08.11.2026

1. **2D-игра, не 3D.** Утверждённый пользовательский концепт 08.11 — яркая плоскостная Этерния, справа адаптивное окно взлома, слева рюкзак, HUD и мини-карта; сцена рисуется отдельными модулями, не одним JPG.
2. **Язык:** всё видимое игроку на русском — «Общее», «Способности», «Банк способностей», «Сохранить», подсказки, действия, диалоги. `HEALTH`, `IS_ALIVE`, `WALK` и другие технические имена остаются английскими, **но видны только с надетым физическим Глазом Оракула**. До получения — gibberish. Глаз находится около спавна, выдаётся только при взломанной палочке. При новом цикле того же слота обучение пропускается: разлом → глаз с полки без диалога. См. [12](12_TECH_LANGUAGE_ORACLE.md).
3. **Перенос способностей:** `WALK` от овечки холодильнику, `FLY` с крыльями на любой форме по 2D-якорям; только `OPEN`/`LOCKED`, минимум блокировок, продвинутые свойства видны после `SCAN_DEPTH`. Банк — отдельная игровая система, не обычные слоты сумки. См. [09](09_PROPERTY_TRANSFER_SYSTEM.md).
4. **Визуальная система:** один светло-голубой неоновый слой изнанки для всех; специальные зрения героев — отдельные overlays. Семь имеющихся палитр меняют только HUD/окно взлома/общие UI.
5. **Актуальная последовательность генераций:** стиль → тайлы → водопад/ambient → слоёная Луна → овечка/холодильник/дерево → универсальные FX и анимации способностей → русское окно взлома/банк → изнанка/Оракул. Первым результатом является живой вертикальный срез с переносом `WALK`, а не полный набор миров.

## 3. Режим производства арта

**У всех 21 артефактов уже есть PNG-мастер** в `assets/artifacts/<ID>/` (concept/icon являются копиями одного изображения). Не тратить новый лимит генераций на все артефакты заново. Следующая работа — **не 3D-модели**, а 2D-риг/слои героя, тайлсеты Этернии, составной водопад, существа и универсальные FX переносимых способностей. Подробная последовательность и бюджет: [10](10_2D_ASSET_PIPELINE.md), **точная очередь небольших генераций — [13](13_GENERATION_BATCHES.md)**, инженерная приёмка: [11](11_2D_IMPLEMENTATION_PLAN.md).

Если конкретному предмету нужен игровой 2D-спрайт/иконка, экспортировать из утверждённого мастера PNG RGBA (обычно 512×512 для UI), подобрать pivot, 2–4 кадра анимации или анимировать шейдером/поворотом без новых генераций. Стиль — полноценная рисованная 2D, чистый контур, насыщенные цвета, минимальное свечение, без baked-текста.

**Именование уже существующих файлов:** `<ID>_concept.png` и `<ID>_icon.png`, без обязательного `<ID>_prop.glb`. Для новой анимации — `<ID>_fx_sheet.png` / `<ID>_animation.json` по 2D-пайплайну. Сохранять точные `id`, включая `A05` для портальной пушки. Старый `A02` не возвращать.

## 4. Самостоятельная техническая проверка

- 21 уникальный ID, из них 14 персональных (по два на семерых) и 7 общих. Кристальное сердце `ART-GL-06` должно иметь форму **одного прозрачного розово-сиреневого кристального сердца**.
- Визуальная форма соответствует `shape` и выбранной простоте, без прежних офисных моделей.
- Есть проверенный концепт/иконка для каждого реально созданного предмета; они **побайтовые копии одного мастера**, не объявлять 42 независимые иллюстрации. `render_status` меняется только после фактической работы. 3D-модели не генерировать.
- У каждого предмета есть своя операция на типизированном движке, но **существование этих операций пока проектное**: нельзя писать «реализовано», пока не проверен код.
- Особый QA для `PRISM`: **треугольный прозрачный кристалл**, без булавки; особый QA для `HOURGLASS`: **песочные часы**, без будильника; для `RUNE`: **руна**, без офисной печати.
- При необходимости править каталог/JSON согласованно в `main` (или в коротком PR с последующим удалением временной ветки); готовый Godot-код не менять без отдельного задания. Не брать дизайн из старых экспериментальных веток.
- Исторические `docs/archive/38–41` сохранены, но прежние A02/будильник/булавка/детектив Óни и GAME_DIMENSION **устарели**. Приоритет у `docs/canon`.

## Подготовленный 2D-пакет

Все 21 прозрачных мастера находятся в `assets/artifacts/<ID>/`, UI — в `assets/ui/`, портреты и рюкзаки — в `assets/characters/<id>/ui/`. См. [актуальный индекс](../art/ASSET_INDEX.md). Концепт и иконка каждого предмета пока используют один мастер; 3D и игровые операции не созданы. Утверждённые в чате разноцветные палитры имеют приоритет над более ранними цветами промптов; Руна и Призма зафиксированы контрольными суммами.
