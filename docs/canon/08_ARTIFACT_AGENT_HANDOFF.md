# 08 — Передача агенту: арт, пиксель-арт и артефакты

> V3, 09.11.2026. Этот файл не даёт разрешения на автоматическую массовую генерацию ассетов и тем более на удаление старых прототипов.

## Основное художественное направление
Один насыщенный мягкий **детальный 2D pixel art** с уютными пастельными цветами и читаемыми контурами, без мыла, 3D-рендера и неонового киберпанк-смешения. Пиксельные блоки достаточно крупные для читаемости; не закреплять 16x16 как универсальный стандарт. Стартовые тесты масштаба Луны 96×128, 128×160, 128×192, при необходимости до 256 по высоте — **кандидаты**, утверждать по фактическому размеру героя на экране. Не путать размер исходного спрайта и видимый масштаб камеры.

Луна: характерная чиби-ведьма, круглая оправа очков, пастельно-сиренево-розовые волосы, фиолетовая остроконечная шляпа, палочка. Всегда сверяться с художественными референсами текущей сессии: конкретные позы/цвета могут меняться в процессе.

## Обязательная последовательность
1. Сверить **текущую рабочую ветку** Pixel Art экспериментов, не перезаписывать её без явной просьбы.
2. Создать **один** канонический тест-спрайт Луны на прозрачном фоне, показать 1:1 рядом с травой и холодильником в сцене. Убедиться, что грани настоящие пиксельные, прозрачность чистая, узнаваемый силуэт читается.
3. По одному отдельному изображению/позе персонажа, одному существу, одному предмету; только после проверки допускается генерация серии.
4. Вся анимация из отдельных согласованных кадров, спрайтшит собирать программно, не просить модель нарисовать 16 разных маленьких кадров в одном коллаже и затем нарезать.
5. Одна спокойная повторяемая базовая трава; поверх независимые мелкие блуждающие клевер/цветочек/камешек/грибочек/кустик с детерминированным seed; не перегружать всю поверхность одинаковыми яркими деталями.
6. Разделить размеры, pivot, collision, sprite anchors, direction/idle/walk/cast. Реальная сцена в Godot важнее красивого отдельного PNG.

## Артефакты
Все существующие ID 21 артефакта из [07](07_ARTIFACT_CATALOG.md) сохраняются. Старые PNG — **референсы и placeholders**, не финальный стиль. Новые картинки должны отражать функции (Зеркало — наблюдение и, возможно, фиксация камеры; Монокль — невидимый носитель ската, Губка — остаточный эффект). Функция важнее цвета или имитации старого PNG. Не рисовать каждому предмету глаза, лапки и крылья.

**Отличать статус:** КАНОН (функция 21 артефакта на уровне текущего каталога) / ПРОЕКТ (места находок, расширение Зеркала, камеры, уникальные редкие бонусы) / НЕ ГОТОВО (финальные пиксельные мастера, спрайт-листы, интеграция в Godot).

## Нельзя менять на своё усмотрение
- Три публичных мира — упразднены; основной только Этерния.
- Ввод `CHARACTER` не раскрывает готовый список персонажей.
- Тёмная и белая глубины — **одна** Пустота.
- Они — удалённый первый прототип, а не злодей или обычный побочный NPC из середины игры.
- Полный deep ending НЕ требует прохождения шести мини-историй.
- Новая стилистика не означает разрешение выбросить существующие Godot-системы без аудита.
- Не выдавать изображения за готовые анимации/функциональные объекты, пока их нет в игре.

## Результат каждой партии
Список входных референсов, подтверждение размеров/пиксельного масштаба, путь конкретного спрайта, кадр из Godot в настоящем размере, отметки о готовом/placeholder, выявленные несоответствия. Для ветки — отдельный PR с картинками и чеклистом. Без массового merge только из-за того, что ассеты технически существуют.
