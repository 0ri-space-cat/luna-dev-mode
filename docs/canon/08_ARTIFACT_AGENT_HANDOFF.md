## 2. Утверждённые автором изменения — НЕ переосмыслять

- **Руна** (`ART-LU-01`): небольшой магический камень с символом, не офисная печать.
- **Призма** (`ART-GL-04`, `PRISM`): **простой цельный прозрачный треугольный кристалл** с сиренево-бирюзовыми переливами; внутри маленькая плоская картинка/силуэт мира. Без иглы, булавки, ручки и механизма. Управляет секретным переходом `GAME_DIMENSION = 2D` в специально созданные 2D-платформерные секции. После сюжетного финала режим доступен также через рамку игры.
- **Песочные часы** (`ART-GL-01`): обычный легко узнаваемый сказочный силуэт песочных часов, фиолетово-бирюзовый парящий песок. Управляют `WORLD_TIME_SCALE`, ускорением/замедлением/паузой **ВСЕГО игрового мира** (с безопасным освобождением держателя и UI от паузы). Никаких будильников.
- **Компас** (`ART-GL-05`): золотой волшебный компас; меняет направление и силу гравитации в ограниченной зоне. Заменил старый **A02 — локальный Якорь времени**, который не должен генерироваться как часть актуального набора.
- **Свиток** (`ART-GL-02`) заменил кассету; **Зеркало** (`ART-GL-03`) заменило перископ. У Юки **Скоба**, а не степлер. Остальные короткие названия и формы — ровно из каталога.
- Из предметов убрать офисные элементы, современную USB-электронику, ножки/лица без надобности, «случайные волшебные механизмы». Результат должен сразу читаться как руна, клубок, губка, фонарь, песочные часы, призма.
- **Обычная палочка Луны** уже умеет менять маршруты **одного NPC** и адреса дверей. Клубок Юки показывает пути наглядно и редактирует несколько точек/маршрутов быстрее; он не является обязательным разрешением на сам принцип изменения NPC-маршрутов.
- **Апгрейд палочки:** игрок делает в озере копию, берёт **копию**, оставляет **оригинал на земле**, и **копией взламывает оригинал**, повышая `SCAN_DEPTH`, `TARGET_RANGE` и прочие поля, вплоть до `DEVELOPER_MODE`. Не использовать устаревшую обратную последовательность.
- Старые N-01…N-04 детективные квесты Óни отменены; у неё только N-01 «Гонка с эхом» и N-02 «Парад на опережение» с временными траекториями.

**Отдельное правило геймдизайна:** система перков, XP/LEVEL и покупаемых навыков **отменена**; не возвращать её при разработке артефактов и персонажей. **Глубокая эмпатия Леи** — встроенное с начала зрение потребностей животных, причин эмоций и направленных связей. **Луна** сопереживает по характеру и может рано найти **Кристальное сердце `ART-GL-06`**, дающее лишь тип/цвет и силу эмоции. Её палочка меняет простые параметры настроения без глубокого анализа причин. Ни один герой не покупает эмпатию за XP. Артефакты дают операции над миром, не проценты бонусов.

## 3. Режим производства арта

**Сначала** один читаемый isolated concept для каждого ID по промпту из JSON, без текста/героев/водяных знаков. Затем — одна единообразная квадратная прозрачная иконка на предмет. Финальные 3D-модели `.glb` изготавливать только после подтверждения силуэтов, не выдавать 2D-картинки за готовые игровые модели.

Рекомендуемый размер иконки: 512×512 PNG с альфа-каналом. Внешний вид: стилизованное 3D как рисованное 2D, чистые контуры, приятные насыщенные цвета, немного магического свечения. Каждый предмет отличается по силуэту. Не вставлять надписи названий внутрь артов.

**Именование файлов:** `<ID>_concept.png`, `<ID>_icon.png`, `<ID>_prop.glb`. Сохранять точные `id` из манифеста, включая `A05` для портальной пушки. Не переиспользовать `A02`, не создавать несколько коллизирующих ID.

## 4. Самостоятельная техническая проверка

- 21 уникальный ID, из них 14 персональных (по два на семерых) и 7 общих. Кристальное сердце `ART-GL-06` должно иметь форму **одного прозрачного розово-сиреневого кристального сердца**.
- Визуальная форма соответствует `shape` и выбранной простоте, без прежних офисных моделей.
- Есть отдельные концепт/иконка для каждого реально созданного предмета, не фиктивные ссылки. `render_status` меняется только после фактического создания.
- У каждого предмета есть своя операция на типизированном движке, но **существование этих операций пока проектное**: нельзя писать «реализовано», пока не проверен код.
- Особый QA для `PRISM`: **треугольный прозрачный кристалл**, без булавки; особый QA для `HOURGLASS`: **песочные часы**, без будильника; для `RUNE`: **руна**, без офисной печати.
- При необходимости править каталог/JSON согласованно, не трогая `main`, чужие ветки и готовый Godot-код без явного отдельного задания.
- Старые docs/38–41 оставлены в Git для истории, но их описания A02/будильника/детектива Óни — **устаревшие**. Приоритет у docs/canon.
