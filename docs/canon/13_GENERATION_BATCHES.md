# 13 — Очередь точечных генераций: что заказывать в каком порядке

> **Практическое ТЗ / 08.11.2026.** Проект LUNA: DEV MODE — рисованная 2D игра. Следует [общему арт-пайплайну](10_2D_ASSET_PIPELINE.md) и [миграционному плану Godot](11_2D_IMPLEMENTATION_PLAN.md). Это производственный чеклист, **файлы ещё не созданы**, если не названы существующими в реестре. Генерации считать запросами к изображению/серии, не обещать, что за один запрос получится идеальный spritesheet. Реальный бюджет зависит от качества и ручной нарезки.

## Неподвижный технический шаблон промпта

**Базовое описание**, добавлять к каждому запросу: «LUNA: DEV MODE, polished hand-drawn fantasy 2D cartoon game sprite, cute expressive fairy-tale world, dark violet clean outlines, saturated lime grass, purple cliffs and pink flowers, turquoise waterfalls, softly luminous cyan and magenta crystals, clear readable silhouette, flat sprite suitable for a Godot 2D game, consistent orthographic pseudo-isometric/front-three-quarter 2D view matching the approved scene reference, no 3D render, no plastic toy model, no scene-wide compositing, no baked UI text, no watermark. Use an even transparent RGBA cutout where specified.»

**Соглашения:** 64×64 логическая клетка окружения; персонажи размером по игровым пропорциям, `pivot` от подошв; согласовать со screenshot 1280×720. Отдельная картинка для каждого вида или один компактный sheet с **одинаковыми ячейками**. Если генератор вернул кривые границы, не размножать ошибку: вырезать лучшие формы и исправить edge-matching вручную. Для каждой партии хранить `source.png`/референс, `prompt.md` (или `generation.json`), `sheet.png`, `atlas.png`, `material.json`, `animation.json`, `anchors.json`, контрольные суммы и статус.

**Не генерировать заново** уже существующие: 21 мастер артефактов, портреты/рюкзаки героев, тысячи SVG кнопок, вкладок и пиктограмм. Сначала проверить `assets/artifacts/`, `assets/characters/`, `assets/ui/`. Подключение к Godot делается отдельной задачей.

## Приёмы снижения расхода генераций

- **Костная анимация** Луны и животных из одной нарезанной модели, циклы idle 4 ключа, ходьба 4–6 фаз, реакция 2 ключа; генератор не должен выдавать 40 разных полнофигурных артов.
- **Вода** имеет 4–6 нарисованных кадров, но высота водопада определяется числом повторённых середины; брызги и туман — кодовые particles/UV.
- **Трава, кусты, кристаллы** живут через `CanvasItem` shader и локальную фазу, а светлячки/бабочки — через seeded-spawner. Не рисовать десятки комбинаций «тайл + бабочка».
- **Способности**: иконка `WALK`, `FLY` и пр. может быть простым нарисованным SVG, а визуал свойств — общим sheet + anchor. `FLY` не требует отдельного кадра полного холодильника с крыльями.
- **Шейдеры:** изнанка для всех **одна** светло-голубая с неоновым контуром; эмпатия, невидимые мосты, временные траектории — отдельный visual overlay, без перерисовки тайлов.
- **Русский UI** генерировать текстом движка: вкладки/кнопки/подсказки. Английские CAPS только у технических ключей; до Оракула pseudo-glyphs. Семь существующих тем UI обновляются кодом, не семью отдельными картинками кнопки «Сохранить».
- **Призма** — существующий авторский 2D PNG и единый эффект разделения слоёв; никакой новой 3D-секции.

## Как писать точные промпты для sheets

### Пример для водопада

> «На прозрачном фоне один модуль водопада для LUNA: DEV MODE, вид рисованного 2D-уровня в уже утверждённой сиренево-бирюзовой палитре. Sheet **4 одинаковые ячейки 128×128**, четыре последовательные фазы воды; фиксированное положение верхнего и нижнего шва, одинаковый силуэт и ширина струи, плавное бесшовное зацикливание 4→1. Без скалы, текста, рамок, других объектов; обе боковые границы одинаковые для каждого кадра. Не изменять освещение/толщину линии по кадрам.»

### Пример для крыльев

> «Один 2D sprite sheet универсальных сказочных крыльев, **левая и правая отдельно**, 4 ключевых фазы раскрытия, ещё одна сложенная; ширина, точка крепления и палитра одинаковы, контур тёмно-фиолетовый, форма дружелюбная. На прозрачном фоне, без тела и персонажей, без букв и дополнительных предметов. Крылья должны одинаково крепиться по бокам бочки, дерева, овечки или холодильника с программным изменением масштаба.»

### Пример для Луны

> «Утверждённая рисованная Луна: большая фиолетовая шляпа со звёздами, розово-сиреневые волосы, большие круглые очки, фиолетовое худи с кошкой и кулон-полумесяц. Только один 2D-персонаж в устойчивом базовом ракурсе, со стабильными пропорциями и толстым читаемым контуром, отдельные части тела для анимационного рига. **Никакого 3D-рендера, пластиковых рук, пропадающих носков, пересечений волос с одеждой**; точное сходство с утверждённым авторским рисунком. Сделать сначала master, затем cutout-sheet из этого master, не рисовать новую Луну на каждом кадре.»

## Формы отклонения и записи результатов

Перед каждой следующей партией сохранять:
```yaml
batch_id: 14
name: universal_wings
reference_revision: 2026-11-08_2d_style
generator_calls: 1
required_outputs: [left_wing, right_wing, folded, frame_0, frame_1, frame_2, frame_3]
pivot: [back_left, back_right]
visual_layers: [back_wings, front_wings]
integration_target: PropertyOverlayResolver/FLY
review:
  silhouette: pending
  equal_cell_size: pending
  seamless_loop: pending
  alpha: pending
  godot_anchor_test: pending
status: planned
```

**Отчётность:** указывать `generated`, `cutout`, `rigged`, `animated`, `integrated`, `tested` отдельно. Если есть только один красивый PNG, писать «исходник получен»; если скомпонован костями и играет цикл — «анимация готова»; если работает свойство и save/load — «игровая механика готова».

**Что точно не делать сейчас:** 21 новая генерация артефактов «ещё лучше», семь копий каждой травы под тему персонажа, 10 видов NPC одновременно, полные кадры 24 FPS водопада, второй 3D-мир, отдельные огромные JSON/PNG для каждой комбинации `WALK/FLY/FIRE_BREATH`.
