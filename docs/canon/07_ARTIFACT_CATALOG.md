# LUNA: DEV MODE — каталог артефактов для ассет-производства

> Обновлено 07.11.2026. **20 артефактов: 14 персональных (по 2 для каждого персонажа) + 6 общих (из них A02 и A05 уже были в старом каталоге).** Все перечисленные ниже возможности — **дизайн-концепты, пока не реализованы**. Источник: docs/38, 41 и новый docs/canon. Для загрузки в генератор/таблицу использовать [машинный реестр](asset_manifest.json).

## Принцип

Каждый артефакт имеет конкретную операцию над системой Entity/Effects/Relations/Routes/Time/Camera, а не просто усиление атаки. У персонажа остаются **его собственные** основные инструменты (палочка, консоль, меч Ори, колба Мии, кулон Леи, леденец и рюкзак Тоффи, рука Óни). Два предмета ниже — дополнительные находки. Каждая имеет собственную модель, иконку и короткую анимацию активации.

**Физическая правда:** артефакты существуют постоянно; персональный предмет обычно **видим только в соответствующем виде изнанки**. Игрок с глубокими знаниями может обнаружить коллизию, адрес, положение или распознать его другим инструментом. Обычный владелец может пользоваться своим предметом сразу после нахождения; другие герои могут подобрать реальный объект, но сложные операции требуют подходящего инструмента или продвинутого взлома. Не создавать уникальные предметы из пустоты по флагу перехода на героя.

**Статус поля и ID:** IDs ART-.. — новые стабильные проектные ключи, A02/A05 — сохранённые IDs V1. Место — предложение для наполнения общей карты, а не сюжетный замок. Параметры написаны английским CAPS и являются **предлагаемым API/UI**, а не утверждением, что они уже есть в Godot.

## Персональные находки: два на героя

### Луна

#### ART-LU-01 — Печать «ЕСЛИ» / IF Stamp

- **Модель:** Круглая лавандовая сургучная печать на короткой ручке, внутри плавает пиксельный знак вопроса и три маленьких переключателя.
- **Палитра:** `#9B7CF6/#68F0DC`. **Эффект активации:** При касании вокруг цели на миг появляется кольцо WHEN → IF → DO.
- **Техническое действие:** Привязывает к одной Entity реакцию на условие: когда событие происходит, выполнить одно разрешённое действие. **Поля редактора:** `EVENT_TRIGGER`, `CONDITION`, `ACTION`, `RULE_DURATION`.
- **Где искать:** Академия Этернии, на полях учебной доски по правилам. **Почему виден только профильному герою:** Читается в параметрическом слое Луны как отдельный предмет, тогда как остальным кажется плоской меткой.
- **Ограничения:** Не создаёт произвольный код, не применяется к глобальным системам; ограничение числа активных правил. **Приоритет:** P1.

#### ART-LU-02 — Ластик непослушных правок / Oops Eraser

- **Модель:** Пухлая конфета-ластик с сиреневым корпусом, бирюзовыми пиксельными крошками и двумя ушками.
- **Палитра:** `#BD8FF6/#FFE8FA`. **Эффект активации:** Вытирает изменённые цифры как меловые и возвращает прежний вид объекта.
- **Техническое действие:** Открывает локальную историю редактирования одной Entity и откатывает выбранное изменение без возврата всего мира назад. **Поля редактора:** `EDIT_HISTORY`, `REVISION_ID`, `REVERT_PROPERTY`.
- **Где искать:** WORLD 00, контейнер тестовых ошибок. **Почему виден только профильному герою:** Видим Луной на слое EDIT_HISTORY, остальным выглядит пятном-потёртостью.
- **Ограничения:** Только сохранённые ревизии данного объекта; не отменяет решения и действия других существ. **Приоритет:** P1.

### Юки

#### ART-YU-01 — Клубок маршрутов / Route Spool

- **Модель:** Маленькая парящая катушка с неоново-розовыми нитями и кубическими креплениями.
- **Палитра:** `#FF69C8/#FFF1FB`. **Эффект активации:** Нити тянутся по настоящим невидимым связям к пространственным якорям.
- **Техническое действие:** Показывает реальные пространственные связи и позволяет перепривязать один существующий выход к другому валидному узлу. **Поля редактора:** `ROUTE_GRAPH`, `LINK_TARGET`, `LINK_ENABLED`.
- **Где искать:** Невидимая ветка моста ET_CREEK_GORGE. **Почему виден только профильному герою:** Только в пространственной сетке Юки; другим кажется пустой петлёй на перилах.
- **Ограничения:** Не создаёт несуществующие уровни; связь меняет маршрут, а не физическую геометрию. **Приоритет:** P1.

#### ART-YU-02 — Степлер пространства / Seam Stapler

- **Модель:** Игрушечный розово-металлический степлер с двумя разомкнутыми светящимися скобами.
- **Палитра:** `#F65FB7/#91ECFF`. **Эффект активации:** Сшивает две поверхности яркой пунктирной строчкой, внутри которой видна другая сторона.
- **Техническое действие:** Создаёт локальный пространственный шов между двумя отмеченными поверхностями в одной загруженной области. **Поля редактора:** `SEAM_POINT_A`, `SEAM_POINT_B`, `SEAM_ACTIVE`.
- **Где искать:** Техчердак Литтаса, за невидимой дверью. **Почему виден только профильному герою:** Юки видит контур шва, остальные — странную пустую щель.
- **Ограничения:** Работает только с безопасными поверхностями и проверенной коллизией; не дублирует межмировую портальную пушку. **Приоритет:** P2.

### Ори

#### ART-OR-01 — Штамп-подменыш / Asset Swap Stamp

- **Модель:** Белый цилиндрический штамп с вращающимися гранями в форме дерева, двери, гриба и чайника.
- **Палитра:** `#EFFAFF/#85D9FF`. **Эффект активации:** Предмет рассыпается на отдельные бело-голубые кубики и складывается в другую модель.
- **Техническое действие:** Мгновенно меняет MODEL_ASSET на одну из заранее собранных форм; отдельно выбирается профиль коллизии, Entity ID сохраняется. **Поля редактора:** `MODEL_ASSET`, `COLLIDER_PROFILE`, `PRESERVE_ENTITY_ID`.
- **Где искать:** Ремонтный двор Литтаса, шкаф битых заготовок. **Почему виден только профильному герою:** Детали и штамп проявляются в модульном зрении Ори.
- **Ограничения:** Нельзя тихо заменить память/личность живого существа; только валидные готовые ассеты. **Приоритет:** P1.

#### ART-OR-02 — Скобы чужих деталей / Component Clips

- **Модель:** Пара магнитных хромированных скоб, соединённых бело-голубым голографическим шнуром.
- **Палитра:** `#EAF9FF/#A2C9FF`. **Эффект активации:** Два предмета на секунду показывают схему своих внутренних компонентов и обмен меток.
- **Техническое действие:** Меняет местами один совместимый компонент у двух существующих предметов: колёса, шарнир, источник звука, лёгкость. **Поля редактора:** `COMPONENT_A`, `COMPONENT_B`, `SWAP_COMPONENT`, `VALIDATE_COMPATIBILITY`.
- **Где искать:** Склад прототипов WORLD 00. **Почему виден только профильному герою:** Видимы как отдельные компоненты только Ори; остальным кажутся крепёжными гайками.
- **Ограничения:** Не переносит сознание, ID или отношения; при конфликте физических типов операция отменяется. **Приоритет:** P2.

### Мия

#### ART-MI-01 — Самоходная пипетка / Flow Dropper

- **Модель:** Стеклянная капельница с четырьмя крошечными ножками и синей плавающей каплей вместо глазка.
- **Палитра:** `#376FE8/#9FFFEF`. **Эффект активации:** Капля рисует светящийся маршрут вдоль пола и труб, затем жидкость течёт по нему.
- **Техническое действие:** Редактирует направление и очередность потока по реально соединённым поверхностям и сливам. **Поля редактора:** `FLOW_PATH`, `PUMP_DIRECTION`, `FLOW_RATE`.
- **Где искать:** Сервисная зона Нью-Парижа, внутри соединённой водосточной сети. **Почему виден только профильному герою:** Мия видит плавающие линии течения и саму пипетку; другим — обычная мокрая отметка.
- **Ограничения:** Не пропускает вещество сквозь герметичную стену и не создаёт бесконечные жидкости. **Приоритет:** P1.

#### ART-MI-02 — Губка-флешка / Residue Sponge

- **Модель:** Мягкая индиговая квадратная губка с миниатюрным разъёмом, внутри которой видны пузырьки цветного света.
- **Палитра:** `#4B40BF/#6DCBFF`. **Эффект активации:** Впитывает невидимый остаточный эффект, на поверхности появляются его пиксельные полосы.
- **Техническое действие:** Захватывает остаточный эффект из одной поверхности и переносит/нейтрализует его в другом месте. **Поля редактора:** `CAPTURE_RESIDUE`, `STORED_EFFECT`, `RELEASE_RESIDUE`, `NEUTRALIZE`.
- **Где искать:** Переулок Литтаса с высохшей, но всё ещё действующей лужей. **Почему виден только профильному герою:** В эффектном зрении Мии выглядит яркой губкой; другим — сухая клякса.
- **Ограничения:** Только один сохранённый эффект; не копирует состав и не нарушает типовые правила нейтрализации. **Приоритет:** P1.

### Лея

#### ART-LE-01 — Бусины личного пространства / Boundary Beads

- **Модель:** Две зелёные стеклянные бусины и золотой полумесяц на короткой гибкой нитке.
- **Палитра:** `#65C47A/#EBCB79`. **Эффект активации:** Мягкие золотые окружности вокруг NPC показывают комфортную дистанцию.
- **Техническое действие:** Настраивает допустимое расстояние следования и границы персональной зоны участников отношений. **Поля редактора:** `FOLLOW_DISTANCE`, `PERSONAL_SPACE_RADIUS`, `FOLLOW_PERMISSION`.
- **Где искать:** Аллея Этернии у группы слишком привязавшихся зверушек. **Почему виден только профильному герою:** Видимы в аурах Леи между двумя связанными существами.
- **Ограничения:** NPC может отказаться следовать; настройка не принуждает симпатию и не переписывает истинную волю. **Приоритет:** P1.

#### ART-LE-02 — Семечко слухов / Mood Seed

- **Модель:** Круглое салатовое семя, два листика-антенны и маленький золотой колокольчик.
- **Палитра:** `#86E893/#F7C85B`. **Эффект активации:** Из семечка расходятся волны, по существующим связям вспыхивают короткие цветные линии.
- **Техническое действие:** Рассылает короткий социальный сигнал по выбранным разрешённым связям (собраться, отойти, предупредить), не меняя навсегда отношения. **Поля редактора:** `SOCIAL_SIGNAL`, `RECIPIENT_LINKS`, `SIGNAL_DURATION`.
- **Где искать:** Сад Нью-Парижа, у цепочки испуганных зверушек. **Почему виден только профильному герою:** Сигнал и объект видны Лее в эмоциональной изнанке, остальные видят лишь шевеление травы.
- **Ограничения:** Только знакомые/открытые направленные связи, действующие лица сохраняют право не реагировать. **Приоритет:** P2.

### Тоффи

#### ART-TO-01 — Монокль великой опоры / Carrier Monocle

- **Модель:** Оранжевый монокль в форме улитки, внутри миниатюрный силуэт ската с платформой на спине.
- **Палитра:** `#F9A44B/#FFED9E`. **Эффект активации:** Подсвечивает, на ком реально стоит предмет, и тонкие линии крепления.
- **Техническое действие:** Показывает HOST_ENTITY/CARRIED_BY и позволяет безопасно закрепить небольшую платформу или груз на движущемся существе. **Поля редактора:** `HOST_ENTITY`, `RIDER_ANCHOR`, `ATTACHMENT_MODE`.
- **Где искать:** Под летающим островом Нью-Парижа, на спине невидимого ската. **Почему виден только профильному герою:** Сам монокль и опорные линии видны только Тоффи в скрытой экологии.
- **Ограничения:** Не переносит целый мир и не повреждает гигантское существо; крепление требует свободной поверхности. **Приоритет:** P2.

#### ART-TO-02 — Фонарик «Я тебя вижу!» / Shared Reveal Lantern

- **Модель:** Мягкий янтарный фонарик с полосатой ручкой и большим круглым глазком.
- **Палитра:** `#FF9B39/#FFE47A`. **Эффект активации:** Световые пузырьки ненадолго делают невидимое животное заметным для всех рядом.
- **Техническое действие:** Создаёт ограниченную зону общего визуального обнаружения выбранных скрытых существ без изменения их коллизий. **Поля редактора:** `REVEAL_TARGET`, `REVEAL_RADIUS`, `REVEAL_DURATION`.
- **Где искать:** Забытый сад Нью-Парижа, за следом невидимого существа. **Почему виден только профильному герою:** Тоффи видит предмет через слой HIDDEN_BEINGS; остальные — только тёплый отблеск на земле.
- **Ограничения:** Взгляд может вызвать ответное внимание существа; не уничтожает его природную скрытность навсегда. **Приоритет:** P1.

### Óни

#### ART-ON-01 — Лента вчера / Echo Ribbon

- **Модель:** Голубая катушка киноплёнки с полупрозрачной лентой, на которой светятся крошечные силуэты.
- **Палитра:** `#70DFFF/#CBF6FF`. **Эффект активации:** Разворачивает цепочку прозрачных предыдущих положений объекта, как у бегущего следа.
- **Техническое действие:** Позволяет прокрутить последние записанные состояния движения одного объекта и закрепить маршрут в виде временных указателей. **Поля редактора:** `TRACE_WINDOW`, `TRACE_SCRUB`, `PATH_MARKERS`.
- **Где искать:** Награда за новую N-01 «Гонка с эхом» на плавающем испытательном обломке VOID. **Почему виден только профильному герою:** Прежде чем добыть, видна только Óни на временных следах; после получения можно передать другому герою.
- **Ограничения:** Показывает зарегистрированное прошлое, не меняет его; без записи показывает пустой интервал. **Приоритет:** P1.

#### ART-ON-02 — Мел завтрашнего шага / Next-Step Chalk

- **Модель:** Голубой трёхгранный мелок с тремя разными призрачными кончиками.
- **Палитра:** `#58CFFF/#ADE8F7`. **Эффект активации:** На земле веером возникают три возможных прозрачных траектории, одна становится чуть ярче.
- **Техническое действие:** Позволяет назначить следующую точку движения согласившемуся NPC/живому предмету и сразу увидеть пересчитанный вероятный путь. **Поля редактора:** `FUTURE_PATH`, `NEXT_WAYPOINT`, `PATH_PREVIEW`.
- **Где искать:** Награда за новую N-02 «Парад на опережение» в Этернии. **Почему виден только профильному герою:** До получения виден Óни в слое FUTURE_PATH; после можно использовать любым героем с подходящей целью.
- **Ограничения:** Не предсказывает гарантированное будущее, не контролирует чужую волю и не переписывает прошлое. **Приоритет:** P1.

## Общие артефакты — шесть инструментов системного контроля

### A02 — Якорь времени / Time Anchor

- **Модель:** Латунные песочные часы в футуристическом ободке, одна песчинка зависла посредине. **Палитра:** `#F9CC86/#71E8FC`.
- **Техническое действие:** Сохраняет локальный снапшот одной Entity и восстанавливает её состояние через выбранное время. **Поля:** `SNAPSHOT_TARGET`, `SAVE_STATE`, `RESTORE_STATE`.
- **Визуальный эффект:** Объект накрывается тонким янтарным контуром снимка, затем может вернуться в сохранённое состояние. **Находка:** Часовая башня Этернии, L-07; известный адрес позволяет попасть раньше. **Видимость:** Обычный физический артефакт, доступный любому.
- **Граница:** Не перематывает время всего мира, не возвращает безнадёжно удалённые сохранения. **Приоритет:** P0.

### A05 — Портальная пушка / Portal Tool

- **Модель:** Игрушечная портальная пушка со светящимися кольцами, двумя сменными цветами и очень коротким стволом. **Палитра:** `#FF6FA8/#62E5F0`.
- **Техническое действие:** Создаёт переход между двумя существующими валидными якорями/адресами; можно переназначить один конец. **Поля:** `ANCHOR_A`, `ANCHOR_B`, `TARGET_LOCATION`, `PORTAL_ACTIVE`.
- **Визуальный эффект:** На безопасных поверхностях возникают два кольца с узорами координат. **Находка:** Сборка у Юки Y-04; дополнительные физические экземпляры можно найти в мире. **Видимость:** Обычный артефакт, геометрия портала видна всем.
- **Граница:** Не создаёт новых сцен или геометрии, проверяет физический безопасный выход. **Приоритет:** P0.

### ART-GL-01 — Дирижёрский будильник / World Clock

- **Модель:** Круглый пузатый будильник с двумя стрелками, четырьмя ножками и висящим над ним маленьким ключом. **Палитра:** `#D6A7FF/#62F2E3`.
- **Техническое действие:** Меняет масштаб времени всей симуляции (пауза, замедление, ускорение), включая автономных NPC и таймеры эффектов. **Поля:** `WORLD_TIME_SCALE`, `WORLD_PAUSE`, `WORLD_RESUME`.
- **Визуальный эффект:** При ускорении окружение оставляет короткие шлейфы, при остановке пылинки зависают. **Находка:** WORLD 00, макет системных часов в дальнем тестовом отсеке. **Видимость:** Обычный артефакт с очень скрытым адресом; виден всем после нахождения.
- **Граница:** Без глобального обратного хода на первом этапе: настоящий WORLD_REWIND потребует согласованных снапшотов всех сцен и отдельного технического решения. **Приоритет:** P2.

### ART-GL-02 — Кассета повторителя / Command Cassette

- **Модель:** Полупрозрачная мини-кассета с пиксельным узором из трёх кнопок PLAY/REC/STOP и светящимися катушками. **Палитра:** `#7D70E8/#F5A3E7`.
- **Техническое действие:** Записывает несколько типизированных операций взлома и применяет их повторно к подходящим выбранным объектам. **Поля:** `RECORD_COMMANDS`, `COMMAND_TEMPLATE`, `TARGET_FILTER`, `BATCH_APPLY`.
- **Визуальный эффект:** Сыгранная операция изображается полосой световых пиктограмм и повторяется по объектам. **Находка:** WORLD 00, отсек автотестов. **Видимость:** Физически видна всем; распознать пользу можно после изучения команд.
- **Граница:** До 4 операций и 8 целей; не повторяет самоудаление, глобальные команды и опасные действия. **Приоритет:** P2.

### ART-GL-03 — Перископ любопытства / Curiosity Periscope

- **Модель:** Крошечный телескоп с объёмным стеклянным глазом, штативом в виде кошачьих лап и бирюзовой кнопкой. **Палитра:** `#93E5F6/#A890FF`.
- **Техническое действие:** Открепляет камеру от героя, позволяет наблюдать ближайшую зону и следовать за выбранной Entity, сохраняя тело игрока на месте. **Поля:** `CAMERA_DETACH`, `CAMERA_TARGET`, `CAMERA_RADIUS`.
- **Визуальный эффект:** От предмета вылетает полупрозрачный глазок-камера на светящейся леске. **Находка:** Нью-Париж, студия наблюдений возле летающей башни. **Видимость:** Обычный объект, может быть спрятан за секретным пространственным переходом.
- **Граница:** Не управляет NPC, не становится FIRST/SECOND PERSON и не переносит героя через препятствия. **Приоритет:** P2.

### ART-GL-04 — Булавка плоскости / Flat Pin

- **Модель:** Треугольная розово-бирюзовая булавка, одна половина которой выглядит полностью плоской как бумага. **Палитра:** `#FF8ECD/#65E8F6`.
- **Техническое действие:** Рано открывает доступ к параметру GAME_DIMENSION = 2D для специально созданной секретной платформер-секции. **Поля:** `GAME_DIMENSION`, `DIMENSION_TARGET_SCENE`, `RETURN_TO_3D`.
- **Визуальный эффект:** При использовании объёмный мир складывается в боковую плоскость как объёмная книжка. **Находка:** Скрыта в слое служебного интерфейса WORLD 00; требуется догадаться, как взломать отображение объекта. **Видимость:** Обычный предмет после извлечения из UI; до этого виден как плоская декоративная заклёпка.
- **Граница:** Не превращает все три открытых 3D-мира в полноценную 2D-игру; после финала та же настройка есть в рамке. **Приоритет:** P3.

## Совместимость со старым списком из docs/38

Старый каталог не отменён и не затирается. **A01–A12** уже существует в дизайнерском документе; семь основных инструментов персонажей считаются их базовым снаряжением, не дополнительными бонусами. Из старых системных находок мы взяли **A02 TIME ANCHOR** и **A05 PORTAL TOOL** и подробно описали их визуал и контроль. Также сохраняются A03 LAB BEACON, A12 TRACE LENS, остальные legacy предметы и **AX01–AX12** (камень гравитации, эмпатическая брошь, линза фауны, камень якоря и др.) как резерв для будущей расстановки/проверки на пересечения.

**Пересечения, которые сознательно разведены:**

- Якорь времени A02 возвращает **один объект** к снимку; ART-GL-01 меняет время **всей симуляции**. Полный мировой rewind отдельно потребовал бы накопления глобальных снимков и пока не обещан.
- Пушка A05 соединяет **существующие адресные якоря**; степлер Юки ART-YU-02 создаёт **локальный шов между физическими поверхностями**.
- Штамп Ори ART-OR-01 меняет готовую модель при сохранении Entity ID; скобы ART-OR-02 меняют один функциональный компонент двух совместимых объектов.
- Следы Óни ART-ON-01 показывают и размечают уже бывшие пути, а ART-ON-02 настраивает **следующий waypoint** согласившейся цели и пересчитывает прогноз.
- Перископ ART-GL-03 перемещает только камеру-датчик, тогда как FIRST/SECOND PERSON из рамки меняет точку зрения/режим управления персонажем.
- Булавка ART-GL-04 даёт ранний доступ к **специальной** 2D-секции; после финала GAME DIMENSION можно выбрать в рамке без предмета.

## Контроль бюджета и порядок генерации

**Первый пакет (P0 + приоритетные P1):** A02, A05, ART-LU-01, ART-OR-01, ART-MI-01, ART-TO-02, ART-ON-01. Для каждого: 1 изолированный prop-concept, 1 прозрачная квадратная иконка, 1 маленькая схема активации. Это самые понятные визуальные различия функциональных артефактов.

**Остальные:** P1 — после первого пакета; P2 — при готовности соответствующей игровой системы; P3 — 2D-бонус. Не заказывать двадцать финальных 3D-моделей, пока не утверждены формы и техконтракты.

**Технический набор для каждого ассета:** `<ID>_prop.glb` (после моделирования), `<ID>_icon.png` (прозрачная иконка 512×512), `<ID>_concept.png` (постановочный референс), анимации `idle / reveal / activate / pickup`. Использовать ID для имён файлов, чтобы не потерять связи с мануалом и инвентарём.

## Важные ограничения

1. Артефакт не может редактировать чужие файлы/операционную систему и не обязан исполнять произвольный код. Сложные настройки представлены безопасными типизированными полями.
2. Каждая операция имеет физически понятный результат, проверяемую валидность и безопасный откат. Не добавлять невидимые сюжетные флаги только ради ограничения спидраннера.
3. Видимость персонального предмета не меняет его коллизию; его всё равно можно обнаружить косвенными физическими уликами.
4. Нельзя выдавать обладателю предмет, на месте которого в другом скине мира вообще ничего не существует.
5. Это каталог для арт-производства и геймдизайна, **не утверждение о готовых Godot-механиках**.
