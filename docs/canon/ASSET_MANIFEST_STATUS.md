# Текущий статус машинного каталога ассетов

`asset_manifest.json`, `assets/asset_catalog.json`, `assets/manifest.json` и имеющиеся PNG/SVG соответствуют **предыдущему 2D-производственному плану**. Они остаются на месте для совместимости со старыми инструментами, историей проекта и существующими тестами.

Визуальная норма V3: крупный мягкий детальный пиксель-арт, по одному согласованному прозрачному master/кадру за генерацию, проверка в масштабе Godot; не возвращаться к устаревшей 3D эстетике. ID 21 артефакта сохраняются как стабильные ключи. Функциональное описание и альтернативные секретные пути — [07_ARTIFACT_CATALOG.md](07_ARTIFACT_CATALOG.md).

Не воспринимать старые промпты, asset status и географические ссылки на Нью-Париж/Литтас из JSON как **новый сюжетный канон**. Переписывание машинного манифеста и производство финальных PNG — отдельный арт-PR после визуального утверждения. Нельзя менять ID/пути существующих ресурсов только ради смены названия мира.
