# 🌙 LUNA: DEV MODE — первый плейтест Этернии (Godot 4.3)

Это **играбельный 2D vertical slice для проверки управления, визуальных состояний, AI и магического редактора**. Находится в ветке `feat/2d-runtime-foundation` (draft PR #5). В `main` этих изменений пока нет. Вся графика уже лежит непосредственно в репозитории; старый архив ассетов скачивать не нужно.

## Как запустить на macOS

1. Установите **Godot Engine 4.3** (обычную сборку, без .NET).
2. Откройте [ветку с прототипом](https://github.com/0ri-space-cat/luna-dev-mode/tree/feat/2d-runtime-foundation) → `Code` → `Download ZIP`; распакуйте. При работе с Git можно вместо этого сделать `git switch feat/2d-runtime-foundation`.
3. В Godot: `Import` → выбрать **project.godot** в распакованной папке → дождаться импорта.
4. Нажмите **F5 / Run Project**. По умолчанию запускается `scenes/2d/world_2d.tscn`.
5. Начальное разрешение — **1280×800**. Для комфортного просмотра рекомендуем не уменьшать окно.

## Управление

| Кнопка | Действие |
| --- | --- |
| WASD / стрелки | Ходьба |
| Shift | Бег |
| Space | Взмах палочкой |
| Q | Реакция Луны |
| E | Контекстное взаимодействие рядом с разломом, озером, Оракулом или узлом связей |
| ЛКМ по существу рядом | Открыть окно взлома после знакомства с разломом |
| U | Самовзлом палочки после получения дубликата |
| Z / Y | Отмена / повтор игрового изменения |
| F5 / F9 | Сохранение / загрузка Этернии |
| F6 | Просмотр палитр HUD семи героев; **управляемым персонажем остаётся Луна** |
| Esc | Закрыть инспектор |

## Маршрут тестирования (около 5–10 минут)

1. **Движение:** пройтись по поляне и побегать по диагонали; проверить повороты, движение ног, рук, палочки и камеру.
2. **Живая поляна:** посмотреть на воду, кристаллы, растения и движущихся овечку, уточку и слайма. Трава должна выглядеть непрерывной, без рамок каждого тайла.
3. **Первое открытие:** приблизиться к круглому разлому в левой верхней части поляны (`E`). После этого можно выбрать дерево или холодильник поблизости и открыть редактор.
4. **Оживление:** у дерева или холодильника включить `IS_ALIVE`. У неживого предмета должны появиться лицо/конечности и движение. Изменить `MOVE_SPEED`, `BEHAVIOR_MODE` или `BASE_COLOR` и посмотреть эффект.
5. **Копирование:** в редакторе выбрать `COPY`; затем попробовать `Z` (отмена) и `Y` (возврат). `DELETE` требует подтверждения, и его также можно отменить.
6. **Повышение доступа:** у Озера отражений в правой нижней части поляны нажать `E`, затем `U`. В палочке должен появиться доступ `АРХИТЕКТОР`, а в редакторе — дополнительные параметры.
7. **Оракул:** подойти к механическому глазу справа сверху и нажать `E`. Глаз Оракула раскрывает технические обозначения расширенных свойств.
8. **Узел связей:** проверить магический терминал справа до и после повышения доступа. Ответ должен различаться.
9. **Постоянство мира:** `F5` → изменить объект, переместить Луну → `F9`. Состояние игрока, параметров и копий должно восстановиться.

## Что пока специально не завершено

- Рисунки Луны и NPC — самостоятельные векторные заготовки с процедурной анимацией суставов. Покадровой финальной анимации волос, выражений и одежды пока нет.
- Слоты инвентаря и хотбар визуализированы, но полноценная предметная система и переключение активного артефакта ещё не перенесены в эту сцену.
- 12 настоящих PNG-тайлов травы загружаются из `assets/2d/eternia/terrain/`; кодовая генерация остаётся резервным вариантом при отсутствующем файле. Переходы между рельефами, полноценные рисованные скалы, анимированный водопад и другие биомные наборы ещё не подготовлены.
- `F6` только показывает разные темы интерфейса: игровые персонажи Юки и другие герои ещё не доступны в этом срезе.
- Прототип проверяется в CI на Godot 4.3 (включая отрисовку реальных кадров); отдельный финальный тест на Mac пока зависит от ручного запуска.
