# Исторический архив LUNA: DEV MODE

**Статус всех файлов в этой папке: УСТАРЕВШИЕ КОНЦЕПЦИИ / HISTORY ONLY.**

Текущие решения собраны в **[едином указателе](../canon/00_START_HERE.md)**. Любое противоречие между этим архивом и docs/canon решается в пользу docs/canon, даже если в старом документе написано «АВТОРИТЕТНЫЙ», «ПРИНЯТО» или «ПОСЛЕДНЯЯ ВЕРСИЯ».

В архиве сохранены **16 старых файлов**:
- 00: прежняя структура игровых уровней и семи рутов;
- 28–35: ранние библия, персонажи, мета-секреты, архитектура и дискуссии;
- 36–42: развёрнутый сценарий, параметры, алхимия, загадки, диалоги, арт-библия, решения V2.

**Из этих файлов можно брать** удачные диалоги, структуру старых сцен, физические рецепты, визуальные образы и конкретные подсказки при переносе в нынешний мир.

**Нельзя возвращать без авторского решения** семь обязательных отдельных кампаний, детективы Óни, покупаемые перки/XP/LEVEL, будильник и булавку вместо песочных часов и призмы, локальный Якорь времени A02, отдельные обязательные мета-барьеры, сюжетные трактовки, отменённые в ноябре 2026.

**Эмоции:** Кристальное сердце Луны (ART-GL-06) показывает грубый сигнал эмоционального состояния; Лея глубже понимает причины чувств, потребности животных и направленные связи.

Архив сохраняется **в одной ветке main вместе с остальным кодом**, отдельные устаревшие ветки не являются источниками игрового дизайна.
